# Author declarations required before submission

The anonymous manuscript no longer uses future-tense promises for the code and data artifact. The following facts still require the corresponding author's confirmation and cannot be inferred from code or experiment logs:

1. Funding agency, grant number, and recipient, or an explicit statement that no funding was received.
2. Competing interests, or an explicit declaration that none exist.
3. Full author list, affiliations, corresponding-author email, and ORCID identifiers.
4. CRediT author contributions for each author.
5. Permanent anonymous artifact URL or journal upload identifier, if the editor requires one in the manuscript.

Do not submit the non-anonymous title page until these fields are completed and checked against the journal portal.
