# 大论文与小论文一体化路线（2026-07-20）

## 1. 最终推荐方向

### 大论文暂定题目

**面向在线短视频评论的可靠多模态情感分析方法与应用研究**

备选题目：

**面向真实退化场景的可审计多模态情感分析方法研究**

第一题更强调实际应用，适合专业型或要求系统落地的硕士论文；第二题更偏算法研究。

### 实际应用场景

输入一段用户发布的产品评测、体验分享或观点短视频，系统联合分析：

- ASR 转写文本中的观点；
- 声音中的语气、强弱和节奏；
- 面部表情与视觉行为；
- 每个模态当前是否清晰、可靠；
- 当前预测是否可信，是否需要人工复核。

输出包括整体情感、分段情感曲线、模态质量报告和低可信提醒，可用于产品口碑分析、视频评论筛选和舆情辅助监测。系统只做辅助分析，不把情感预测当作个人心理状态或事实判断。

## 2. 为什么选这个场景

| 候选应用 | 与现有 MOSI/MOSEI/SIMS 的一致性 | 数据可得性 | 伦理/落地风险 | 结论 |
|---|---|---|---|---|
| 产品评测/短视频舆情 | 高：同为文本+声音+视频的观点表达 | 高：MOSI、MOSEI、CH-SIMS v2、MuSe-CaR | 较低 | **主选** |
| 客服通话情绪监测 | 中：常缺少视频，真实数据多为私有 | 中低 | 隐私与录音授权 | 备选，不作为主线 |
| 在线教育投入度 | 低到中：任务通常是 engagement，不是 sentiment | 中 | 容易发生任务漂移 | 不建议当前切换 |
| 抑郁/心理风险筛查 | 模态相似但任务、标签和责任完全不同 | 低到中，DAIC-WOZ 需申请 | 高风险医疗场景 | 不建议零基础阶段选择 |
| 智能座舱驾驶员情绪 | 多数数据缺少文本，偏视觉/语音情绪识别 | 中低 | 采集和实时系统成本高 | 暂不选择 |

MuSe-CaR 提供超过 36 小时的真实汽车评测视频，适合验证产品视频评论场景。CH-SIMS v2.0 提供 14,563 个中文视频片段，并包含未经人工修正的 ASR 文本，更接近真实中文短视频噪声。

## 3. 小论文正式技术方向

### 暂定中文题目

**模态质量分数可信吗？面向鲁棒多模态情感分析的可审计预算约束辅助学习**

### 暂定英文题目

**Are Modality Quality Scores Trustworthy? Audited and Budget-Constrained Auxiliary Learning for Robust Multimodal Sentiment Analysis**

题目暂不使用 Q-DAMFON，也不急于创造模型缩写。最终命名需要在完整复现最接近工作后确定。

### 小论文核心问题

真实视频评论中的文本、声音和画面会受到 ASR 错误、背景噪声、遮挡、模糊、帧丢失和时间错位影响。现有方法常用特征范数、预测置信度或对齐程度作为“模态质量”，但这些分数可能：

1. 实际是 batch 共享量，而非逐样本量；
2. 被序列长度或特征能量混淆；
3. 随噪声增大反而升高；
4. 没有真正改变模型优化或决策；
5. 作为自由损失权重时自动趋近于 0。

### 方法 v0：审计 + 修复

#### 模块 A：质量代理审计（Quality Proxy Audit）

对每个质量分数检查五项性质：

- **Granularity**：是否真正逐样本/逐片段；
- **Monotonicity**：退化越强，可靠性是否越低；
- **Confound Invariance**：是否主要受长度、音量、padding 或标签强度影响；
- **Actionability**：置换、反转或移除分数是否改变梯度或预测；
- **Non-collapse**：权重是否通过整体趋零来降低损失。

#### 模块 B：干预式可靠性学习（Intervention-Grounded Reliability Learning）

由同一个 clean 样本生成不同强度的退化版本，要求可靠性分数满足相对排序：

$$
s_1 < s_2 \Rightarrow r_m(x^{s_1}) > r_m(x^{s_2}),
$$

其中 $s$ 是退化强度，$r_m$ 是模态 $m$ 的可靠性。额外加入保持语义不变的音量缩放和 padding 变化，要求可靠性基本不变，避免再次学习长度/能量捷径。

这一步学习的是“输入是否可信”，不是直接学习“该模态对情感标签有多重要”。情感任务相关性仍由主模型和任务损失学习，避免把可靠性和任务贡献混成同一个量。

#### 模块 C：预算约束的逐样本辅助优化（Budget-Constrained Sample-wise Auxiliary Learning）

先保留每个样本的蒸馏和对比损失：

$$
L_{aux}^{m}=\frac{1}{B}\sum_{i=1}^{B} w_{m,i}L_{m,i}.
$$

权重由可靠性得到，但一个 batch 内总预算固定：

$$
w_{m,i}=\delta_m\frac{B(r_{m,i}+\epsilon)}{\sum_j(r_{m,j}+\epsilon)}.
$$

因此平均辅助权重始终约为 $\delta_m$，模型不能把全部权重压到 0。高可靠样本承担更多弱模态蒸馏与对比监督，低可靠样本仍保留主任务监督。

该模块优先作为训练期方法设计；如果可靠性头在推理时没有稳定收益，可以在部署时移除，保持较低推理开销。

#### 模块 D：作用性验证（Actionability Verification）

比较正常可靠性、batch 内置换、全局置换、反转、常数分数和已知退化强度构成的 oracle 正对照。只有正常分数在预测或训练中产生稳定、方向正确的影响，才能称为“质量感知”。

### 与 2026 年最近工作的创新边界

小论文不能把“可靠性引导”“逐样本加权”或“质量感知融合”单独写成创新，因为这些概念已经被近期工作覆盖。当前可守住的差异不是再增加一个融合模块，而是把**质量代理本身是否可信、是否真正起作用、是否通过减少总监督量取得表面收益**作为统一研究对象。

| 最近工作 | 已经解决的内容 | 本文必须做出的实质差异 |
|---|---|---|
| CPSC（CVPR 2026） | 用 conformal reliability 进行表示筛选，并按样本可靠性调节单模态分类梯度 | 审计任意质量代理的失效条件；约束的是蒸馏/对比等辅助监督的**总预算**，而非再次提出普通可靠性加权分类损失 |
| QA-MoE（ACL 2026） | 用概率特征方差估计质量，并进行质量感知专家路由 | 不依赖推理期 MoE 路由；验证质量分数在训练梯度和最终决策中是否可作用 |
| 质量作用性诊断（INTERSPEECH 2026） | 通过置换质量分数，发现现有融合决策可能几乎不使用质量 | 从预测端置换扩展到代理有效性、混淆因素、训练梯度和权重坍缩，并提供固定预算修复基线 |
| Robust-MSA（AAAI 2023）及 2026 真实退化评测 | 构造模态噪声并评价鲁棒性 | 研究“用于控制训练的质量分数是否通过审计”，而不是只报告模型在 corruption 下的结果 |
| SAM-LML（EMNLP 2025） | 在噪声/缺失条件下监督模态注意力排序 | 不把注意力排序直接等同于输入质量；显式分离输入可靠性、任务相关性和辅助监督预算 |

因此，当前小论文定位应为：**一篇带修复方法的诊断型方法论文**。主要证据顺序是“发现普遍失效规律 → 提出可复现审计协议 → 给出预算守恒修复 → 在真实退化和视频评论数据上验证”，而不是“堆叠模块后刷新单个 MOSI 指标”。

### 冻结方法前的必要门槛

预算归一化公式本身不足以构成 CCF-B 级创新。正式冻结方法前必须满足：

1. 在至少三类已有质量代理上复现同类失效，而不只是批评当前 MFON 实现；
2. 证明固定预算控制后，收益来自样本间监督重分配，而不是总损失权重变化；
3. 同时报告正常、置换、反转、常数和 oracle 分数，形成正负对照；
4. 与 CPSC、QA-MoE、SAM-LML 和最近作用性诊断完成公式级差异表；
5. 如果审计规律不能跨 MOSI、MOSEI 和 CH-SIMS v2 复现，就降级为硕士论文章节，不包装成期刊核心创新。

## 4. 大小论文之间的关系

```mermaid
flowchart LR
    A["真实短视频评论"] --> B["文本/声音/视觉退化"]
    B --> C["小论文：质量代理审计"]
    C --> D["小论文：预算约束逐样本优化"]
    D --> E["鲁棒情感预测模型"]
    E --> F["大论文扩展：长视频分段与时序聚合"]
    F --> G["应用系统：情感曲线、质量报告、低可信提醒"]
```

小论文解决大论文中的核心算法问题；大论文增加真实视频评论数据验证、长视频分段聚合、系统实现和应用分析。两者不是两套模型。

## 5. 数据集分工

| 数据集 | 小论文用途 | 大论文用途 |
|---|---|---|
| CMU-MOSI | 快速开发、消融、五种子 | 基础英文实验 |
| CMU-MOSEI | 大样本英文验证 | 跨说话人和主题验证 |
| CH-SIMS / CH-SIMS v2.0 | 中文与 noisy ASR 验证 | 中文短视频应用核心数据 |
| MuSe-CaR | 产品视频评论外部验证 | 产品评测真实场景与长视频分析 |

不建议现在自行爬取和标注大规模短视频。先完成公开数据上的方法和系统原型；只有公开数据不能回答论文问题时，才考虑小规模、合规的数据补充。

## 6. 大论文技术章节建议

1. **绪论**：短视频评论分析需求、现实退化和可信性问题。
2. **相关技术与基线复现**：多模态情感分析、MFON、可靠融合和鲁棒学习。
3. **模态质量代理审计方法**：五项审计、现有代理失效规律和实验协议。
4. **预算约束的逐样本可靠优化方法**：小论文完整方法与三数据集实验。
5. **面向视频评论的时序扩展与应用系统**：长视频切分、片段聚合、质量告警和不确定样本复核。
6. **总结与展望**。

第五章不强求再发一篇论文，但必须形成可运行原型和真实案例分析，使“大论文应用”不是在结尾临时加一个界面。

## 7. 系统原型边界

原型第一版只需要完成：

1. 上传或选择一段本地视频；
2. 提取/读取文本、声音和视觉特征；
3. 按片段预测情感；
4. 显示各片段模态质量与总情感曲线；
5. 标记低质量、模态冲突或低置信片段；
6. 导出汇总结果。

不需要一开始就接入抖音、实时爬虫、企业舆情平台或大语言模型。这些会显著增加工程和合规成本，却不直接提高小论文质量。

## 9. 当前边界判断

- 大论文方向可以确定为“可靠短视频评论情感分析”，暂时不再横跳到医疗、教育或驾驶场景。
- 小论文研究问题可以确定为“质量代理审计 + 干预式可靠性学习 + 预算约束逐样本辅助优化”；具体公式仍需通过最近工作复现和上述五项门槛后冻结。
- 这仍是方法 v0，不等于已经证明创新。必须重点对比 Robust-MSA、QMF、PDF、SAM-LML、CPSC、QA-MoE、EBMC 和 2026 年质量分数作用性诊断。
- 只有完成最近工作复现和 novelty-delta 表后，才能冻结论文标题中的“首次”“新型”等表述。
- 当前代码完成的是固定预算修复基线；干预式可靠性学习及其退化监督尚未实现，二者不得在实验记录中混为同一版本。

## 10. 关键公开依据

- [CPSC, CVPR 2026](https://openaccess.thecvf.com/content/CVPR2026/html/Jiang_Multimodal_Learning_on_Low-Quality_Data_with_Conformal_Predictive_Self-Calibration_CVPR_2026_paper.html)：已覆盖 conformal reliability、表示筛选和逐样本梯度校准，是本方法最重要的近邻工作之一。
- [QA-MoE, ACL 2026](https://aclanthology.org/2026.acl-long.1461/)：已覆盖连续可靠性谱、自监督 aleatoric uncertainty 和质量感知专家路由。
- [When Does Quality-Aware Multimodal Fusion Matter?, INTERSPEECH 2026](https://arxiv.org/abs/2606.26473)：置换测试表明，质量分数可能几乎不影响融合结果，是本文作用性审计的直接近邻工作。
- [CH-SIMS v2.0 官方页](https://thuiar.github.io/sims.github.io/chsims)：共 14,563 个中文视频片段，其中未监督部分使用未经人工修正的 ASR 文本，可作为中文真实噪声验证。
- [MuSe-CaR 数据页](https://zenodo.org/records/4134766)：超过 36 小时的真实汽车评测视频，适合作为产品评论应用数据。
- [Robust-MSA, AAAI 2023](https://ojs.aaai.org/index.php/AAAI/article/view/27078)：提供模态噪声分析与鲁棒性评测基准，不能把“首次研究模态噪声”作为本文主张。
- [SAM-LML, EMNLP 2025](https://aclanthology.org/2025.emnlp-main.1084/)：研究噪声和模态缺失下的监督式注意力学习，是可靠性排序相关的重要对照。
