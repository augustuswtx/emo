# 大论文开题与完成方案（2026-09-17）

> 适用范围：以现有 MOSI/MOSEI 预提取特征、受控退化实验和 MFON 改造为研究起点。学位类型、学校开题模板、最低章节/成果要求尚未提供；提交前必须按学校与导师要求调整。本文件不把计划实验写成已有成果。

## 1. 开题暂定题目

**多模态情感分析中的模态可信性评估与自适应学习方法研究**

如导师要求应用限定，可改为“面向视频情感分析的模态可信性评估与自适应学习方法研究”。当前不要用“真实短视频场景”或“复杂环境下的鲁棒情感分析”作为题目中的已完成范围：现有证据来自公开基准的预提取特征和受控扰动。2026-07-20 的[旧路线图](thesis-integration-roadmap-20260720.md)含真实视频/系统目标，现列为可选扩展，不是开题的硬承诺。

## 2. 开题时可直接讲清的四句话

1. **背景**：文本、音频、视觉信息有时退化或相互冲突，模型既要知道输入哪里不可靠，也要决定训练时哪些辅助目标有帮助。
2. **问题**：能区分干净与受扰动输入的分数，不一定适合在不同样本之间分配辅助监督；现有第一阶段实验已观察到这一差距。
3. **研究内容一**：建立模态可信性审计协议，检查分数的退化响应、长度/能量混淆、跨样本可比性和分配作用性；如实报告有效范围与失败边界。
4. **研究内容二**：在固定辅助监督预算下，研究与情感任务更新一致的条件式辅助学习；通过真正的更新效用和匹配对照验证分配机制。

## 3. 大论文两项研究内容

### 内容一：可信性评估及其作用边界（已有基础，待归档完善）

**输入**：MFON 与 P4 的视觉/音频分数，公开情感基准的已有划分，以及受控退化版本。

**产出**：可复现审计程序和分层结果，明确区分三个概念：

- 输入退化响应：受控扰动增强时，分数是否下降；
- 辅助目标代理：高分是否对应更小 KL 等代理误差；
- 训练效用：给该辅助目标更多权重后，任务损失是否改善。

前两项已经有部分证据；第三项需要新实验。C1 的视觉负相关是已发现的边界，不能被论文写作消除。C5 的零化敏感度仅是扰动敏感性代理，不等于真实模态因果贡献。

### 内容二：任务导向的条件辅助学习（拟研究，未获正向结果）

核心思路：在训练数据内部，用与当前样本分离的另一批样本衡量情感任务梯度；比较每个视觉/音频 KL 的更新方向是否可能降低任务损失。若该方向有帮助，则在相同 KL 总预算下提高其权重；若整批都无帮助，则允许停止该辅助更新，并用相同停用掩码的均匀分配对照隔离“停用”收益。

先运行只读梯度与真实小步审计；再决定能否校准原可靠性分数，或需要单独学习轻量效用分数。第一版只改 KL 分配，保留原网络和 InfoNCE，不把新模块堆叠当作创新。

**与小论文关系**：小论文可聚焦内容一发现的机制缺口和内容二的修复方法；大论文再系统展开审计协议、消融、跨设置有效性与失败分析。学位论文的第二项研究不能简单把小论文复制一遍，必须有独立的研究问题、实验或应用边界分析。

## 4. 建议章节与完成标志

| 章节 | 写作任务 | 最低完成证据 |
|---|---|---|
| 第一章 绪论 | 情感分析场景、为什么输入可信性不等于训练效用、研究问题与贡献边界 | 问题链清楚，贡献只写已证明部分 |
| 第二章 基础与实验协议 | MFON、辅助 KL/InfoNCE、固定预算、数据划分、评价指标及相关工作 | 可复现协议与最近邻方法差异表 |
| 第三章 模态可信性评估 | P4 分数与受控扰动、C1/C2/C5 审计、混淆因素和失败案例 | 三种子已有结果准确归档，事后分析明确标注 |
| 第四章 自适应辅助学习 | 任务效用定义、低成本估计、分配规则、预算与停用控制、组件消融 | 单步效用验证、同预算对照、多种子主终点；若不通过则收缩主张 |
| 第五章 泛化与应用边界 | 在预先锁定的独立数据/划分验证，分析模态缺失或退化、效率和失效情形；如学校要求应用实现，再做最小可运行原型 | 至少一个独立确认设置和完整局限；原视频鲁棒性只在有真实原始媒体与相应实验时声称 |
| 第六章 总结与展望 | 两项问题的结论、适用条件与未解问题 | 每条结论能回指到具体表/图/审计 |

章节名称及篇幅以学院模板为准。若第四章没有正向方法结果，第五章要强化审计协议的跨数据集验证和替代策略比较，而不是虚构第二项创新。

## 5. 下周开题材料清单

1. **题目与研究问题**：采用第 1–2 节口径，避免把“可靠性分数有效”设为预定结论。
2. **现状与动机图**：用一张图显示“受控退化响应 → 跨样本代理 → 实际训练效用”是三个不同检验层级；标出已完成和待完成。
3. **已完成工作表**：P4 三种子、C1 三种子审计、C2 seed 1111、C5 seed 1111；报告负面与混合结果，不能只选 Learned 最好的指标。
4. **技术路线图**：旧可靠性头与 MFON 主干保留；新增效用审计、KL 条件分配和匹配控制。每个节点写输入、输出、决定是否继续的条件。
5. **实验计划**：MOSEI 已用部分用于开发/探索；新方法的训练内 meta 批次与独立确认设置提前确定。MAE/Corr 为主，分类和算力为辅；同预算与置换/反向对照是关键。
6. **风险与备选**：若分配收益不稳，转为可信性审计与失败边界研究；若效用估计过慢，先测轻量梯度代理，不承诺必然刷新 SOTA。
7. **学校行政材料**：开题格式、研究生类别、时间节点、导师认可的成果要求和署名信息由作者按真实要求补齐。

## 6. 从开题到定稿的工作顺序

| 时间窗口 | 必须完成 | 完成标志 |
|---|---|---|
| 开题前（下周） | 按第 1–5 节准备题目、问题图、已有结果表、路线图与风险页 | 导师能清楚看到已完成和待验证内容；不把第二项方法写成既成成果 |
| 开题后第一阶段 | 只读梯度 smoke、真实小步效用验证、旧分数是否可校准的判断 | 决定采用“原分数校准”还是“独立轻量效用分数”；若都不成立，停止扩展训练 |
| 开题后第二阶段 | 单种子 KL-only 原型、C4 归因及固定预算机制对照 | 训练过程正确，MAE/Corr 与对照完整，失败情况保留 |
| 开题后第三阶段 | 锁定设计后的多种子与独立确认；必要时补数据集、扰动和效率实验 | 明确方法适用范围，完成小论文或审计型稿件的可复现证据包 |
| 定稿阶段 | 分章节撰写、图表与统计核对、学校格式和导师反馈修改 | 每章结论能回指到真实表/图，摘要与结论不超出证据 |

这些是相对阶段，不是保证日期。训练轮次和外部数据工作量要根据第一阶段结果决定。

## 7. 与导师沟通时建议明确的三个问题

- 学位论文是否要求两项彼此独立的方法贡献，还是允许“审计发现 + 有针对性的修复方法”？
- 学校是否要求真实应用系统或原始视频实验，还是公开基准与方法研究足够？
- 开题报告的页数、模板、截止日期和中期检查时间是什么？

这些是外部要求，不应由当前实验记录推断。当前最先推进的科学工作是[执行路线的 B 阶段](research-execution-roadmap-20260917.md)：远端只读梯度 smoke；它决定第二项研究内容的实现路线。
