## 1. 开题暂定题目

**面向在线视频观点情感分析的非文本模态可信性评估与辅助学习研究**

备选题目：**面向产品评测视频的可靠多模态情感分析方法研究**。

这里的具体领域不是泛泛的“可信多模态学习”，而是在线视频观点与评测
场景：当文本在情感预测中占主导时，如何判断视觉/音频辅助教师监督是否
可信、是否对当前任务更新有用，并据此控制训练。唯一的 CCF-B 小论文在现有
可靠性和固定预算方法上建立训练作用性审计协议；大论文再展开同一问题的
两个分析层次，并补充跨设置与应用边界。

如导师要求应用限定，可改为“面向视频情感分析的非文本模态可信辅助学习方法研究”。当前不要用“真实短视频场景”或“复杂环境下的鲁棒情感分析”作为题目中的已完成范围：现有证据来自公开基准的预提取特征和受控扰动。2026-07-20 的[旧路线图](thesis-integration-roadmap-20260720.md)含真实视频/系统目标，现列为可选扩展，不是开题的硬承诺。

## 2. 开题时可直接讲清的四句话

1. **背景**：文本、音频、视觉信息有时退化或相互冲突，模型既要知道输入哪里不可靠，也要决定训练时哪些辅助目标有帮助。
2. **问题**：能区分干净与受扰动输入的分数，不一定适合在不同样本之间分配辅助监督；现有第一阶段实验已观察到这一差距。
3. **研究内容一**：建立模态可信性审计协议，检查分数的退化响应、长度/能量混淆、跨样本可比性和分配作用性；如实报告有效范围与失败边界。
4. **研究内容二**：在固定辅助监督预算下，审计可靠性、不确定性和目标一致性等分数是否具有训练作用；通过更新稳定性和匹配对照验证分配机制。

## 3. 大论文两项研究内容

### 内容一：可信性评估及其作用边界（已有基础，待归档完善）

**输入**：MFON 与 P4 的视觉/音频分数，公开情感基准的已有划分，以及受控退化版本。

**产出**：可复现审计程序和分层结果，明确区分三个概念：

- 输入退化响应：受控扰动增强时，分数是否下降；
- 辅助目标代理：高分是否对应更小 KL 等代理误差；
- 训练效用：给该辅助目标更多权重后，任务损失是否改善。

前两项已经有部分证据；第三项需要新实验。C1 的视觉负相关是已发现的边界，不能被论文写作消除。C5 的零化敏感度仅是扰动敏感性代理，不等于真实模态因果贡献。

### 内容二：训练分数的作用性审计（已完成单模型筛查，待扩展）

核心思路：把退化检测、目标保真度、更新稳定性和最终分配作用性分成四个检验层级。在相同辅助预算下，对可靠性、不确定性、教师一致性和梯度效用等分数使用 Constant、Gate-only、Permuted 和 Inverse 对照，判断分数能否支持实际训练行为。

P6/P7 已表明最终 checkpoint 的局部梯度效用高度依赖 meta 批次，且无法由测试过的样本自身特征稳定预测，因此停止轻量效用预测器路线。下一步扩展审计协议，而不是继续调预测器或无依据启动训练。

**与小论文关系**：唯一的 CCF-B 小论文同时包含内容一发现的机制缺口和内容二的修复方法，不再拆成两篇投稿。大论文分别展开两个技术层次，并新增跨数据集、跨骨干、应用验证和失败边界分析，避免逐字复制小论文。

## 4. 建议章节与完成标志

| 第二章 基础与实验协议 | MFON、辅助 KL/InfoNCE、固定预算、数据划分、评价指标及相关工作 | 可复现协议与最近邻方法差异表 |

| 第四章 训练作用性审计 | 四层审计协议、分数家族、预算与匹配控制 | 跨分数、数据集、骨干的统一结果及多种子中央对照 |
| 第五章 泛化与应用边界 | 在预先锁定的独立数据/划分验证，分析模态缺失或退化、效率和失效情形；如学校要求应用实现，再做最小可运行原型 | 至少一个独立确认设置和完整局限；原视频鲁棒性只在有真实原始媒体与相应实验时声称 |

章节名称及篇幅以学院模板为准。若第四章没有正向方法结果，第五章要强化审计协议的跨数据集验证和替代策略比较，而不是虚构第二项创新。

5. **实验计划**：MOSEI 已用部分用于开发/探索；五类分数定义、四层审计协议和独立确认设置提前确定。MAE/Corr 为主，分类和算力为辅；同预算与置换/反向对照是关键。
6. **风险与边界**：P6/P7 已停止轻量效用预测路线；当前按跨分数、数据集和骨干的作用性审计推进，不承诺必然刷新 SOTA。
