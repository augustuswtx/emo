# 大小论文一体化路线：非文本模态可信辅助学习

Date: 2026-09-28
Status: current thesis integration plan

## 1. 大论文的具体领域

应用领域：**在线视频观点与产品评测视频的多模态情感分析。**

技术子领域：**文本主导多模态情感分析中的非文本模态辅助学习。**

具体研究对象是文本、视觉、音频共同输入的情感分析模型。在此类模型中，
文本往往承担主要预测作用，视觉和音频通过知识蒸馏、对比学习、提示或融合
提供辅助信息。核心问题不是“怎样再设计一个融合网络”，而是：

1. 视觉或音频输入是否可靠？
2. 冻结单模态教师提供的目标是否适合当前样本？
3. 对该样本执行辅助更新是否有助于独立主任务数据？
4. 如何在计算成本可接受的前提下选择或抑制这些辅助更新？

这使大论文有清楚的对象、作用环节和评价标准，同时与 MOSI、MOSEI、SIMS
以及现有 MFON 代码直接对应。

## 2. 推荐题目

首选：

**面向在线视频观点情感分析的非文本模态可信性评估与辅助学习研究**

备选：

**面向产品评测视频的可靠多模态情感分析方法研究**

首选题目与 MOSI/MOSEI 的在线观点视频来源和当前算法工作直接一致。备选
题目只能在补充产品评测原始视频实验后使用。题目暂不写“通用鲁棒性”或
“复杂场景”，因为当前证据尚未覆盖这些范围。

## 3. 一条完整的研究链

```mermaid
flowchart LR
    A["文本主导的多模态情感模型"] --> B["视觉/音频辅助监督"]
    B --> C["现有小论文基础：输入可靠性评估"]
    C --> D["逐样本损失与固定预算分配"]
    D --> E["发现：可靠性不等于训练效用"]
    E --> F["同一篇论文的关键改进：四层作用性审计"]
    F --> G["跨分数、数据集与骨干验证"]
    G --> H["完成唯一 CCF-B 小论文"]
    H --> I["大论文：可信辅助学习统一框架"]
    I --> J["跨数据集、跨骨干与退化边界"]
```

现有小论文不是被后续工作否定，也不与改进方法拆成两篇投稿。现有版本完成
前半段并发现必须解决的边界；四层作用性审计作为同一篇论文的关键扩展；达到
证据门槛后，整体作为唯一的 CCF-B 小论文投稿。大论文把两个分析层次展开，
并补充跨设置和应用边界验证。P6/P7 已关闭样本内在效用预测路线，不能再把
该方法写成待实现的主贡献。

## 4. 小论文对大论文的直接用途

| 小论文已有内容 | 在大论文中的位置 | 继续使用方式 |
|---|---|---|
| 受控退化与可靠性头 | 第三章“输入可靠性评估” | 判断视觉/音频是否响应建模过的退化，并分析跨退化边界 |
| 逐样本 KL/InfoNCE | 第三、四章公共损失接口 | 作为所有分配方法共同的最小训练单元 |
| 固定预算归一化 | 第四章“任务效用驱动分配” | 保证方法与对照使用相同平均辅助系数 |
| Constant/Permuted/Inverse | 第三至五章公共对照协议 | 判断收益来自分数对应关系、停用还是监督总量变化 |
| C1/C2/C5 负面结果 | 第一章动机及第三章边界 | 证明退化检测不能直接解释为跨样本训练价值 |
| 扰动审计代码 | 第五章泛化与边界 | 在不同数据集、骨干和退化条件下复用 |
| C4 per-sample-only 消融 | 第三章组件归因 | 区分可靠性损失与逐样本预算机制的作用 |

可靠性分数作为被审计的一个代表性分数，不再被当作天然正确的分配真值。
这样既保留已有模型，也尊重已经观察到的负面证据。

## 5. 一篇 CCF-B 小论文与大论文章节

### 唯一小论文：可靠性分数的训练作用性审计

研究问题：输入退化分数是否可信；当该分数被用于训练权重时，是否能通过
目标保真度、更新稳定性和最终分配对照；这种关系能否跨分数、数据集与骨干
复现。

同一篇论文包含四项相互依赖的贡献：

1. 可靠性代理与实现机制审计；
2. 逐样本、固定预算的辅助学习框架；
3. 退化检测、目标保真度、更新稳定性和最终作用性的四层审计协议；
4. Constant、Gate-only、Permuted 和 Inverse 等匹配控制及跨设置证据。

现有草稿是这篇论文的早期版本。只有加入任务效用改进并完成必要实验后，才
作为一个整体投稿 CCF-B；不把两个高度重叠的版本分别投稿。该论文的可靠性
部分对应大论文第三章，作用性审计对应第四章，但成果数量仍是一篇。

### 大论文扩展：统一框架的适用范围

研究问题：输入可靠性和训练效用分别在什么条件下有效，怎样组合，能否跨
数据集和骨干保持作用。

对应第五章。最低要求是三个数据集、两个骨干、退化/缺失实验、效率与失败
案例；不需要为了凑章节再发明第三个无关模型。

## 6. 建议章节结构

| 章节 | 主题 | 与论文关系 |
|---|---|---|
| 第一章 | 文本主导情感模型中非文本辅助学习的问题、研究问题与贡献 | 统一动机 |
| 第二章 | 多模态情感分析、MFON、蒸馏、固定预算、任务效用和评价协议 | 公共基础 |
| 第三章 | 非文本模态可靠性评估与固定预算逐样本辅助学习 | 唯一小论文的基础与问题发现 |
| 第四章 | 非文本模态训练分数的作用性审计与固定预算对照 | 同一篇小论文的核心扩展 |
| 第五章 | 跨数据集/骨干泛化、退化鲁棒性、效率和失败边界 | 大论文新增综合验证 |
| 第六章 | 总结与展望 | 回答三个研究问题 |

大论文不能逐字复制小论文。第三、四章可分别展开同一篇论文中的两个技术
层次；第一、二、五、六章必须补充统一问题定义、理论与相关工作、跨设置验证、
应用边界和综合结论。

## 7. 三个研究问题

- **RQ1 输入层：** 非文本模态可靠性分数能否稳定反映受控退化，并避免
  长度、能量和 padding 混淆？
- **RQ2 优化层：** 可靠性、目标一致性和不确定性等分数能否稳定预测训练
  作用，并在固定预算对照中证明正确分配有效？
- **RQ3 泛化层：** 可靠性和效用分别在什么数据集、骨干、退化与模态条件下
  有效或失效？

RQ1 和 RQ2 由升级后的唯一 CCF-B 小论文共同回答，RQ3 由大论文新增的综合
实验回答。

## 8. 完成判据

### 唯一 CCF-B 小论文进入中央训练矩阵

- C4 组件归因闭环，旧方法的负面结果完整报告；
- 五类分数定义及四层审计协议冻结；
- MFON/MOSEI 的只读审计复现并完成混淆因素检查；
- 中央训练臂、平均辅助预算和停止规则提前固定。

### 唯一 CCF-B 小论文完成

- 可靠性、固定预算和作用性审计形成一个连续问题故事；
- 所有正面和负面分配结果均通过 Constant、Gate-only、Permuted 和 Inverse
  解释；
- 完成至少三个数据集、两个骨干、多种子、鲁棒性和效率证据；
- 现有草稿被整体重写为升级后的方法论文，而不是追加一段新实验。

### 大论文完成

- 两项研究内容共用同一问题、损失接口和评价协议；
- 至少三个数据集和两个骨干；
- 第五章给出可靠性与效用的联合分析，而不是简单拼接论文结果；
- 每条结论都能回指到真实实验表、图或审计记录。

## 9. 数据集分工

现有数据集不整体更换，按研究阶段分工：

| 数据集 | 用途 | 是否用于方法选择 |
|---|---|---|
| MOSEI | 主开发集、效用标签与完整消融 | 是，仅使用 train/valid |
| MOSI | 小样本英文复现与快速消融 | 是，但不单独支撑结论 |
| 当前 SIMS/CH-SIMS | 中文迁移及独立单模态标签分析 | 是 |
| CH-SIMS v2.0 | 方法锁定后的新确认集；条件允许时做原始媒体退化 | 否，冻结设计后一次性评估 |

现有三个测试集已在前期反复查看，不能再称为完全未触碰的独立确认。新增
CH-SIMS v2.0 的主要价值是提供新的确认数据、更多非语言线索和原始片段，
不是为了增加表格行数。MuSe-CaR 的连续情绪、参与度、主题和可信性任务与
当前句级情感回归不完全一致，暂列为应用扩展，不进入核心方法主表。

## 10. 失败时仍保持一体化

P6/P7 已证明当前轻量效用预测器失败，唯一小论文现已转为更广泛的审计型
CCF-B 路线：比较可靠性、不确定性、教师一致性和梯度效用等多类分数，并
扩展到多数据集、多骨干和统一作用性对照。贡献是可信辅助学习的评估协议和
失败边界。是否达到 CCF-B 仍取决于审计广度和证据强度。
