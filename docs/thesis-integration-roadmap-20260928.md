# 大小论文一体化路线：非文本模态可信辅助学习

Date: 2026-09-28
Status: current thesis integration plan

## 1. 大论文的具体领域

**文本主导多模态情感分析中的非文本模态辅助学习。**

具体研究对象是文本、视觉、音频共同输入的情感分析模型。在此类模型中，
文本往往承担主要预测作用，视觉和音频通过知识蒸馏、对比学习、提示或融合
提供辅助信息。核心问题不是“怎样再设计一个融合网络”，而是：

1. 视觉或音频输入是否可靠？
2. 冻结单模态教师提供的目标是否适合当前样本？
3. 对该样本执行辅助更新是否有助于独立主任务数据？
4. 如何在计算成本可接受的前提下选择或抑制这些辅助更新？

这使大论文有清楚的对象、作用环节和评价标准，同时与 MOSI、MOSEI、SIMS
以及现有 MFON 代码直接对应。

## 2. 推荐题目

首选：

**文本主导多模态情感分析中的非文本模态可信辅助学习方法研究**

备选：

**多模态情感分析中的非文本模态质量评估与任务效用驱动学习研究**

首选题目突出应用于哪一类模型和研究哪个训练环节；备选题目突出两项方法
贡献。题目暂不写“真实短视频”“通用鲁棒性”或“复杂场景”，因为当前证据
尚未覆盖这些范围。

## 3. 一条完整的研究链

```mermaid
flowchart LR
    A["文本主导的多模态情感模型"] --> B["视觉/音频辅助监督"]
    B --> C["小论文：输入可靠性评估"]
    C --> D["逐样本损失与固定预算分配"]
    D --> E["发现：可靠性不等于训练效用"]
    E --> F["CCF-B方法：稀疏任务效用标签"]
    F --> G["低成本效用预测与保守停用"]
    G --> H["大论文：可信辅助学习统一框架"]
    H --> I["跨数据集、跨骨干与退化边界"]
```

小论文不是被后续工作否定。它完成前半段并发现了必须解决的边界；后续方法
针对这一边界定义更合适的分配依据；大论文把两个层次统一起来。

## 4. 小论文对大论文的直接用途

| 小论文已有内容 | 在大论文中的位置 | 继续使用方式 |
|---|---|---|
| 受控退化与可靠性头 | 第三章“输入可靠性评估” | 判断视觉/音频是否响应建模过的退化，并分析跨退化边界 |
| 逐样本 KL/InfoNCE | 第三、四章公共损失接口 | 作为所有分配方法共同的最小训练单元 |
| 固定预算归一化 | 第四章“任务效用驱动分配” | 保证方法与对照使用相同平均辅助系数 |
| Constant/Permuted/Inverse | 第三至五章公共对照协议 | 判断收益来自分数对应关系、停用还是监督总量变化 |
| C1/C2/C5 负面结果 | 第一章动机及第三章边界 | 证明退化检测不能直接解释为跨样本训练价值 |
| 扰动审计代码 | 第五章泛化与边界 | 在不同数据集、骨干和退化条件下复用 |
| C4 per-sample-only 消融 | 第三章组件归因 | 区分可靠性损失与逐样本预算机制的作用 |

可靠性分数在后续方法中仍可作为效用预测器的一个输入特征，但不再被当作
天然正确的分配真值。这样既保留已有模型，也尊重已经观察到的负面证据。

## 5. 两篇论文与大论文章节

### 小论文：可靠性评估与固定预算辅助学习

研究问题：输入退化分数是否可信，以及它在固定监督预算下是否具有
可验证的分配作用。

适合形成的贡献：

1. 可靠性代理与实现机制审计；
2. 逐样本、固定预算的辅助学习框架；
3. 退化检测、教师目标代理和训练效用之间的边界证据。

对应大论文第三章，并提供第四章的训练接口与对照协议。

### CCF-B 论文：任务效用驱动的选择性辅助学习

研究问题：能否用稀疏而准确的任务效用标签训练轻量预测器，从而选择真正
有帮助的视觉/音频辅助更新。

适合形成的贡献：

1. 样本-模态辅助更新效用定义；
2. 稀疏标签到低成本效用预测器的摊销；
3. 不确定时停用的保守分配；
4. Gate-only、Permuted、Inverse 等作用性验证。

对应大论文第四章。

### 大论文扩展：统一框架的适用范围

研究问题：输入可靠性和训练效用分别在什么条件下有效，怎样组合，能否跨
数据集和骨干保持作用。

对应第五章。最低要求是三个数据集、两个骨干、退化/缺失实验、效率与失败
案例；不需要为了凑章节再发明第三个无关模型。

## 6. 建议章节结构

| 章节 | 主题 | 与论文关系 |
|---|---|---|
| 第一章 | 文本主导情感模型中非文本辅助学习的问题、研究问题与贡献 | 统一动机 |
| 第二章 | 多模态情感分析、MFON、蒸馏、固定预算、任务效用和评价协议 | 公共基础 |
| 第三章 | 非文本模态可靠性评估与固定预算逐样本辅助学习 | 小论文主体 |
| 第四章 | 稀疏监督的任务效用预测与选择性辅助学习 | CCF-B 论文主体 |
| 第五章 | 跨数据集/骨干泛化、退化鲁棒性、效率和失败边界 | 大论文新增综合验证 |
| 第六章 | 总结与展望 | 回答三个研究问题 |

大论文不能逐字复制两篇论文。第三、四章可复用经过整理的方法与实验，第一、
二、五、六章必须完成统一问题定义、共同协议、跨章节比较和综合结论。

## 7. 三个研究问题

- **RQ1 输入层：** 非文本模态可靠性分数能否稳定反映受控退化，并避免
  长度、能量和 padding 混淆？
- **RQ2 优化层：** 某个样本-模态辅助更新的局部任务效用能否被准确、低成本
  地预测，并用于固定预算分配？
- **RQ3 泛化层：** 可靠性和效用分别在什么数据集、骨干、退化与模态条件下
  有效或失效？

三者分别由小论文、CCF-B 方法和大论文综合实验回答。

## 8. 完成判据

### 小论文完成

- C4 组件归因闭环；
- 已完成负面结果完整报告；
- 不再声称旧可靠性分数已证明正向分配；
- 固定预算和作用性协议可复现。

### CCF-B 方法进入正式训练

- 多 checkpoint、多种子视觉效用标签通过局部小步验证；
- 低成本预测器在完全按 batch/checkpoint 留出的数据上通过预设门槛；
- 预计训练额外开销不超过 15%。

### 大论文完成

- 两项研究内容共用同一问题、损失接口和评价协议；
- 至少三个数据集和两个骨干；
- 第五章给出可靠性与效用的联合分析，而不是简单拼接论文结果；
- 每条结论都能回指到真实实验表、图或审计记录。

## 9. 数据集分工

现有数据集不整体更换，按研究阶段分工：

| 数据集 | 用途 | 是否用于方法选择 |
|---|---|---|
| MOSEI | 主开发集、效用标签与完整消融 | 是，仅使用 train/valid |
| MOSI | 小样本英文复现与快速消融 | 是，但不单独支撑结论 |
| 当前 SIMS/CH-SIMS | 中文迁移及独立单模态标签分析 | 是 |
| CH-SIMS v2.0 | 方法锁定后的新确认集；条件允许时做原始媒体退化 | 否，冻结设计后一次性评估 |

现有三个测试集已在前期反复查看，不能再称为完全未触碰的独立确认。新增
CH-SIMS v2.0 的主要价值是提供新的确认数据、更多非语言线索和原始片段，
不是为了增加表格行数。MuSe-CaR 的连续情绪、参与度、主题和可信性任务与
当前句级情感回归不完全一致，暂列为应用扩展，不进入核心方法主表。

## 10. 失败时仍保持一体化

如果轻量效用预测器失败，大论文仍围绕同一领域完成：第四章改为比较可靠性、
不确定性、教师一致性和梯度效用等多类分数的系统审计；第五章扩展到多数据集
和多骨干。此时贡献是可信辅助学习的评估协议和失败边界，而不是伪造一个
正向分配结果。小论文仍然提供固定预算、对照和审计基础。
