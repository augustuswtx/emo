# 大论文双小论文路线与第一篇 2026 年 10 月投稿冲刺

更新：2026-10-09。用户要求大论文整合**两篇**小论文，并在 2026 年 10 月内**投稿第一篇**。本文件取代[2026-09-28 的单篇路线](thesis-integration-roadmap-20260928.md)中关于“小论文数量”的决定；旧文件仍保留实验历史。投稿不等于录用或见刊，审稿结果由期刊独立决定。

## 1. 投稿目标与论文分工

**第一篇（本月投稿）：** 暂以 [IEEE Transactions on Affective Computing（TAC）](https://www.computer.org/digital-library/journals/ta/tac-general-call-for-papers) 的常规研究论文为目标。TAC 在 [CCF 人工智能 B 类目录](https://www.ccf.org.cn/Academic_Evaluation/AI/)中，常规征稿持续接受投稿；多模态情感识别属于其官方范围。学校若另有认定规则，提交前重新核对。TAC 是题材匹配的候选目标，**不是现有稿件已经达到 B 类录用标准的判断**。

第一篇的科学问题是：**视觉/音频分数能够识别受控退化时，是否也能说明辅助教师目标可信、局部更新有利以及样本权重应该如何分配？** 现有 P4 可靠性头、逐样本 KL/InfoNCE、固定平均预算、C1/C2/C5、P6/P7 是这篇的案例与证据。论文贡献要定位为可复核的作用性审计、匹配对照与失败边界；不能再声称已验证“高可靠性样本应获更高辅助权重”。

**第二篇（第一篇投稿后推进）：** 研究在第一篇揭示的情境依赖下，怎样用可承受的计算成本做**条件化辅助学习**。可探索 meta 情境、任务梯度或验证信号驱动的门控/分配，但具体算法必须由可行性实验决定。第二篇需要新的训练机制、独立对照与跨设置证据，不得把第一篇的 P4 实验换标题重复投稿。

| 维度 | 第一篇：分数作用性审计 | 第二篇：条件化辅助学习 |
|---|---|---|
| 核心问题 | 分数测量了什么，能否支持分配结论 | 已知分数不足时，如何构造有效且经济的训练决策 |
| 主要技术产物 | 四层审计协议、逐样本证据结构、同预算对照 | 新的条件化选择/分配算法及计算成本控制 |
| 主要实验 | P4 案例、C1/C2/C4/C5、P6/P7 与跨数据集复核 | 新方法对 Constant、原 P4、Permuted/Inverse、有效梯度参照的配对实验 |
| 不得重复作为“新贡献” | 第二篇不能重报第一篇审计表作为方法收益 | 第一篇不能预先声称第二篇算法有效 |
| 大论文章节 | 第三章：可信性测量与作用性审计 | 第四章：条件化辅助学习方法 |

大论文第五章再做共同数据协议下的跨数据集、跨骨干、退化与效率综合分析；第一、二、六章分别承担统一问题、相关研究和总结。两篇共享任务背景与代码接口，但各自须有独立的研究问题、方法/协议贡献和主实验。

## 2. 2026-10-09 已有证据与投稿缺口

已有：MOSEI 三种子 Repaired MFON / Constant / Learned，MOSI 三种子开发结果，三种子受控与跨退化审计，C1 三种子视觉 `-KL` 负相关，C2 seed 1111 四组最终日程结果，C5 seed 1111 零化分层，P6/P7 服务器终端结果，代码和图源。`-KL` 是教师—学生一致性代理，**不是教师目标正确性的独立测量**。统一清单见[来源状态](actionability-evidence-status-20261007.md)。

关键缺口按投稿影响排序：

1. **可追溯原始证据：**P6/P7 的四个 JSON、C2 四组训练/测试日志与 checkpoint 哈希尚未归档到本地；现有证据清单明确标为缺失。原始文件未到之前，不把终端转录当作独立复核。
2. **组件归因 C4：**Per-sample-only 尚未完成，不能把 P4 与 MFON 的差异归因于可靠性损失或分配。
3. **分配方向 C2：**Permuted/Inverse 只有 seed 1111，MAE 与 Corr 方向不一致；若要讨论分配机制，需要配对 1112/1113 或将结论限定为单种子探索。
4. **泛化范围：**跨分数/数据集/骨干的统一审计未完成。已有 MOSEI test 及 MOSI test 被反复查看；不能称新分析是未触碰盲测。
5. **稿件：**TAC 目录仍是旧 MOSI 草稿，尚未合并 NCA 大修稿中的 MOSEI/C1/C2 结果；作者、基金和声明仍有占位符；现环境无 TeX 引擎，最终 PDF/页数未核实。

这些缺口意味着当前稿件**尚未达到可负责提交 TAC 的状态**。本月可以把“完成提交动作”作为交付目标，但必须先过下述证据与格式闸门；B 类录用不能承诺。

## 4. 第一篇的最低可审查证据

- 明确区分退化识别、教师—学生一致性/目标正确性、更新稳定性、最终分配作用性四层；`-KL` 只测一致性，不能将它的负相关直接写成教师目标错误的证据。
- 在同一平均辅助权重预算下报告 Constant、Learned、Permuted、Inverse；C4 分离 reliability loss 与逐样本分配。只报告已完成的种子，并保留负面结果。
- 至少把现有 MOSI/MOSEI 的一致与冲突结果放进同一表，解释 MOSI 是开发证据、MOSEI 也是后来被查看过的测试结果。
- 报告长度/能量混淆、未见扰动、文本主导、零化代理分层、训练与推理成本。来源文件、参数、随机种子和 checkpoint 哈希可核对。
- 不以“提升 0.0025 MAE”独立支撑新方法贡献；主结论必须是审计发现及其适用边界。

目前尚无第二骨干实现。若月底仍只有 MFON，标题、摘要和结论均须限定为 **MFON 案例**；TAC 审稿风险较高。新增骨干或分数家族只能在结果前固定计算口径，不能对已查看的 test 指标迭代选择。

## 5. 本周实际执行顺序

1. 在服务器打包并下载 P6/P7 四个 JSON；本地已有[一行归档命令](actionability-evidence-status-20261007.md)。同时列出 C2 原始日志/检查点哈希。
2. 核对服务器已有任务、磁盘、GPU 与 C4 目标文件。若 C4 未运行且前置条件齐全，按[服务器执行卡](c4-server-run-20261009.md)上传校验过的启动包并启动单种子；不并行占同一 GPU。
3. C4 完成后再决定是否按已冻结日程补 C2 1112/1113。失败和不显著差异同样入论文。
4. 同步改稿、核对参考文献和图表，不等 GPU 训练结束才开始写作。

此排期是可执行的冲刺安排，不是对 TAC 录用概率或审稿时长的预测。
