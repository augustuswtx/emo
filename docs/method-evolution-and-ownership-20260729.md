# 小论文方法演变与贡献边界

## 一句话说明

当前方法已经从“给MFON叠加几个动态模块”，改为：

> 先检查模态质量分数是否可信，再用受控退化学习可靠性，并在每批辅助监督总量不变的条件下，让可靠性决定监督如何分配。

暂定描述名为“审计驱动的干预式可靠性预算学习”。名称尚未冻结，最终取名要等待单种子正式实验。

## 三个版本的区别

| 阶段 | 当时怎么做 | 发现的问题 | 当前处理 |
|---|---|---|---|
| 旧Q-DAMFON | MFON + ALW + DPG + CSS | 三种子没有稳定超过修复后MFON；CSS把噪声当高质量；自由权重有趋零方向 | 不再作为主方法，只保留失败原型和消融证据 |
| 固定预算过渡版 | 用`align`为逐样本KL/InfoNCE分配固定预算 | 训练机制正确，但视觉AUROC仅0.567、音频0.642，预测几乎不受影响 | `align`降级为弱代理对照，不跑25轮 |
| P1 | 通用三联退化可靠性头 + 能量不变性 + 固定预算辅助学习 | 视觉AUROC 0.981，但音频0.501；2轮clean性能明显下降 | 保留视觉头，淘汰通用音频头，不跑正式训练 |
| 当前P1.1 | 音频时序可靠性头 + 可靠性全强度监督 + 主任务10轮渐进扰动 | 本地23项测试通过，GPU效果未知 | 下一步做2轮服务器烟雾测试与160样本审计 |

## 当前方法怎么工作

### 1. 输入和基础模型

输入仍然是文本、视觉和音频。MFON继续承担文本编码、提示交互、多模态融合和情感预测。冻结的视觉、音频编码器以及KL蒸馏、InfoNCE对比学习也继续保留。

这部分属于MFON基础，不是本文原创。

### 2. 构造三联退化样本

对同一个视觉或音频样本构造：

1. 干净版本；
2. 轻度退化版本；
3. 重度退化版本。

轻度和重度版本使用同一个随机噪声方向，只改变强度，减少“两个随机噪声恰好难度不同”造成的比较误差。

### 3. 学习视觉和音频可靠性

视觉、音频分别使用一个轻量可靠性头。训练时要求：

```text
干净分数 > 轻度退化分数 > 重度退化分数
```

排序间隔随严重度差异变化。严重度差异越大，可靠性分数应拉开得越明显。

配对加噪和排序监督已有SAM-LML等先例，不能单独宣称为本文首创。

### 4. 防止模型利用简单捷径

可靠性头只读取经过逐时间步归一化的统计特征，并显式检查：

- padding位置改变时，分数不能改变；
- 同一内容整体放大或缩小时，分数尽量不变；
- 噪声增强时，分数应单调下降。

目的不是让模型通过“数值越大或序列越长”猜质量，而是学习退化导致的结构变化。

### 5. 固定预算分配辅助监督

每个样本保留独立的KL和InfoNCE损失。可靠性只决定同一批次内谁获得更多辅助监督，但每批平均权重精确保持不变。

通俗地说：

> 老方法可能一边改变分配，一边偷偷减少总作业量；当前方法固定全班作业总量，只改变作业分给谁。

QMF已经讨论动态融合权重与静态权重保持相同期望。因此，“保持平均权重”不能笼统写成首次提出。本文的限定区别是：对训练期逐样本KL/InfoNCE，在每个有限mini-batch内精确守恒。

### 6. 退化样本参与主任务训练

重度退化版本进入情感预测训练，使主模型实际接触低质量视觉和音频。可靠性较低时，对应的蒸馏与对比辅助监督减少，但情感标签监督仍然保留。

这使“输入可靠性”和“对情感任务是否有用”不被直接混成同一个概念。

## 哪些模块已经退出主方法

- `ALW`：自由动态辅助权重，不再作为主方法；
- `CSS/norm`：已被审计证明方向错误；
- `align`：只作为弱质量代理对照；
- `DPG`：旧完整原型种子波动较大，当前P1不启用；
- 旧名称`Q-DAMFON`：不再准确代表当前论文，暂不继续使用。

## 当前可以主张什么

只有在后续实验通过后，论文才可以主张：

1. 五维审计能够识别质量分数的粒度、单调性、混淆、作用性和坍缩问题；
2. 有限批次精确预算能够排除监督总量变化这一混淆；
3. 通过审计的可靠性分配比常数、置换、反转和弱代理更有效；
4. 方法在噪声、缺失和未知退化下提高鲁棒性，同时不过度损伤clean性能。

目前第1项已有部分证据，第2项完成工程验证，第3和第4项尚无正式结果。

## 不能主张什么

- 不能说MFON结构是本文原创；
- 不能说首次使用噪声排序监督；
- 不能说首次提出动态质量加权；
- 不能说当前方法已经优于MFON；
- 不能把2轮烟雾测试写成正式性能结果；
- 不能在跨数据集实验完成前声称普遍适用。

## 当前实验闸门

P1服务器烟雾测试需要证明：

1. 可靠性头确实得到梯度并更新；
2. `q_gap_v`和`q_gap_a`向正值发展；
3. 固定预算均值仍严格正确；
4. checkpoint能够保存、加载和推理；
5. 新分数在同一审计协议下明显优于`align`。

只有以上条件成立，才进入MOSI seed 1111的正式25轮试验。
