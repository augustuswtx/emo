# DAMFON: 面向鲁棒多模态情感分析的动态自适应模态特征优化网络

## 摘要

多模态情感分析旨在联合文本、视觉和声学信息识别人类表达中的情感倾向，是情感计算和多模态理解中的基础任务。现有方法通常通过跨模态注意力、张量融合或多任务学习建模模态间交互，但在实际训练中仍面临显著的模态不平衡问题：文本模态往往具有更高的信息密度和更稳定的语义表示，而视觉与声学模态更容易受到遮挡、噪声、说话人习惯和采集环境的影响。近期的 MFON 通过模态提示注意力、模态内知识蒸馏和模态间对比学习对弱模态进行优化，在一定程度上缓解了弱模态欠优化问题。然而，MFON 仍依赖固定的蒸馏与对比损失权重，需要针对不同数据集进行代价较高的超参数搜索；同时，其提示向量对所有样本保持静态不变，难以适应样本级模态质量差异；训练过程也未显式区分高质量样本与高噪声样本，容易在早期受到不稳定梯度干扰。

为解决上述问题，本文提出动态自适应模态特征优化网络 DAMFON。DAMFON 包含三个互补模块。首先，本文设计自适应损失权重机制，将蒸馏与对比学习权重分解为可学习基值、训练进度系数和样本质量分数三类因子，使模型能够在不同训练阶段和不同样本质量条件下动态调整辅助损失强度。其次，本文提出动态提示生成模块，根据当前样本的文本语义和弱模态特征生成实例级提示，从而替代静态可学习提示，使跨模态注意力具备样本感知能力。最后，本文构建基于质量估计的课程采样策略，在训练早期优先使用高置信、低噪声样本，并随训练推进逐步引入困难样本，以提升收敛稳定性。三个模块共享统一的样本质量估计，形成从特征优化、损失调节到数据采样的闭环。

本文计划在 MOSI、MOSEI、CH-SIMS、UR-FUNNY 和 MUStARD 五个公开数据集上验证 DAMFON 的有效性，并将所提出模块部署到 MFON、Self-MM 和 CubeMLP 三类代表性架构中检验其通用性。实验将从主结果、模块消融、质量函数对比、训练动态、噪声鲁棒性和计算开销等角度进行系统分析。预期结果表明，DAMFON 能够在保持较低额外参数和推理开销的前提下，更稳定地优化视觉与声学弱模态表示，并提升多模态情感分析的整体性能。

**关键词**：多模态情感分析；模态不平衡；知识蒸馏；动态提示；课程学习；自适应损失权重

## 1. 引言

多模态情感分析（Multimodal Sentiment Analysis, MSA）旨在从文本、视觉和声学等多种信号中推断说话人的情感状态或态度倾向。与单纯依赖文本的情感分析相比，多模态情感分析能够利用面部表情、语音语调、停顿节奏和语义内容之间的互补关系，因此更接近真实人际交流中的情感理解过程。例如，同一句“很好”在不同语境下可能表达真诚赞同，也可能表达讽刺或不满；仅凭文本很难准确判断，而面部表情和语音语调通常能提供关键线索。因此，如何充分整合不同模态的信息，是多模态情感分析中的核心问题。

近年来，随着预训练语言模型、跨模态 Transformer 和多模态融合网络的发展，多模态情感分析取得了明显进展。早期方法主要关注融合策略，例如通过张量外积显式建模模态交互，或通过低秩分解降低融合维度。随后，基于注意力机制的方法进一步增强了跨模态依赖建模能力，使文本、视觉和声学特征能够在序列层面进行交互。更近的研究开始关注多模态学习中的模态不平衡问题，即不同模态在信息密度、噪声水平和优化难度上的差异会导致训练过程偏向强模态。尤其在以 BERT 表示为文本编码器的设置下，文本模态通常收敛更快、判别性更强，而视觉和声学模态更容易成为被动补充甚至噪声来源。

模态不平衡直接影响多模态模型的训练行为。一方面，强文本模态可能主导融合层和预测层的梯度更新，使模型在训练中逐渐忽略视觉与声学信息。另一方面，弱模态本身的输入质量不稳定，例如视频中的遮挡、面部角度变化、光照差异，以及音频中的环境噪声和说话人差异，都会使弱模态特征难以形成稳定的判别表示。当弱模态特征质量较低时，简单拼接、加权求和或注意力融合不仅无法带来增益，甚至可能引入额外噪声，削弱整体性能。因此，多模态情感分析不仅需要设计更强的融合模块，还需要从优化角度提升弱模态表示的可学习性和可靠性。

MFON 针对弱模态欠优化问题提出了模态特征优化框架。该方法通过模态提示注意力（Modal Prompt Attention, MPA）增强文本与弱模态之间的交互，通过模态内知识蒸馏将单模态教师知识迁移到多模态特征中，并通过模态间对比学习拉近文本与弱模态表示。相比仅关注融合结构的方法，MFON 将优化目标显式施加到视觉与声学模态上，因而更直接地缓解弱模态表示质量不足的问题。然而，MFON 的辅助损失权重仍然是固定超参数，需要通过网格搜索或随机搜索确定。固定权重存在三个局限：第一，权重对数据集、随机种子和模型初始化敏感，迁移到新数据集时需要重新搜索；第二，训练早期弱模态表示尚未稳定，过强的蒸馏或对比约束可能放大噪声梯度；第三，固定权重对所有样本一视同仁，无法区分清晰表情样本和遮挡严重样本，也无法区分高质量音频和强噪声音频。

除固定损失权重外，现有弱模态优化方法还存在两个容易被忽视的问题。其一是提示静态性。MFON 中的提示向量作为可学习参数，在训练完成后对所有样本保持相同。静态提示可以提供任务级先验，却无法根据具体样本的模态质量进行调整。对于视觉信息丰富的样本，模型可能需要强调细粒度表情区域；对于视觉信号受损的样本，模型则应降低对视觉细节的依赖，转而利用更稳健的文本或声学上下文。单一静态提示难以同时适应这些情况。其二是采样静态性。标准训练通常在每个 epoch 内随机打乱所有样本，使干净样本和噪声样本同时进入训练。此时模型在尚未学到稳定跨模态对齐能力之前，就需要处理大量困难样本，容易导致训练路径不稳定。

基于上述观察，本文提出 DAMFON（Dynamic Adaptive Modal Feature Optimization Network），从损失、提示和采样三个层面共同增强多模态情感分析的鲁棒性。首先，本文提出自适应损失权重机制（Adaptive Loss Weighting, ALW），将每个辅助损失权重分解为任务级可学习基值、时间级训练进度系数和样本级质量分数。该分解既保留了权重学习的灵活性，也使权重变化具有明确解释：模型在训练早期降低辅助损失强度，在高质量样本上增强蒸馏和对比学习，在低质量样本上抑制潜在噪声梯度。其次，本文提出动态提示生成模块（Dynamic Prompt Generation, DPG），根据文本全局语义和弱模态特征为每个样本生成实例级提示，从而让跨模态注意力能够根据输入状态调整关注模式。最后，本文提出课程采样策略（Curriculum Sampling Strategy, CSS），利用样本质量分数构建从易到难的训练过程，使模型先学习可靠样本中的跨模态规律，再逐步处理噪声更高、质量更不稳定的样本。

本文的贡献可以概括为以下四点。第一，本文从模态不平衡和弱模态优化角度重新审视固定辅助损失权重的局限，提出由基值、进度和质量三因子组成的自适应损失权重机制。第二，本文设计实例级动态提示生成模块，使提示学习从任务级静态参数扩展到样本级条件生成。第三，本文将质量估计同时用于损失调节和课程采样，形成统一的质量感知训练框架。第四，本文不仅在 MFON 上实现 DAMFON，还计划将相关模块迁移到 Self-MM 和 CubeMLP，以验证该框架并非依赖单一架构的特化改进。

## 2. 相关工作

### 2.1 多模态情感分析

多模态情感分析研究如何联合语言、视觉和声学信息进行情感预测。早期代表性方法 TFN 通过张量外积显式建模三种模态之间的高阶交互，但外积操作会导致特征维度迅速增长，增加计算和存储负担。LMF 使用低秩分解近似高阶融合，在保留交互能力的同时降低参数规模。随着 Transformer 在序列建模中的成功，MulT 等方法将跨模态注意力引入 MSA，使不同模态能够在时间维度上相互查询和对齐。此类方法显著增强了模态间依赖建模能力，但仍主要从融合结构角度提升性能。

随后，一些研究开始关注自监督、多任务和模态专属学习。Self-MM 通过为不同模态构造自监督标签，使每个模态在训练过程中都能获得更直接的监督信号。CubeMLP 则使用 MLP 结构混合多模态特征，在较低复杂度下实现有效融合。MFON 进一步指出视觉和声学模态存在欠优化问题，并通过提示注意力、知识蒸馏和对比学习专门增强弱模态表示。本文与 MFON 关系最为直接，但关注点不同：MFON 主要设计弱模态优化结构，而本文进一步研究这些优化目标在训练过程中应如何动态施加，以及提示和样本采样如何适应样本级模态质量差异。

### 2.2 多模态知识蒸馏

知识蒸馏最初用于将复杂教师模型的知识迁移到轻量学生模型中，后来被广泛应用于多任务学习、多模态学习和模型压缩。在多模态场景中，知识蒸馏可以发生在不同粒度上：可以从单模态教师迁移到多模态学生，也可以从多模态教师迁移到单模态模型，还可以在特征、预测分布或关系结构层面进行约束。对于 MSA 而言，视觉和声学模态常常缺少稳定监督，因此通过预训练单模态编码器提供蒸馏信号是一种自然选择。

现有蒸馏方法通常假设蒸馏强度是固定的，或者仅根据任务整体表现进行调整。然而，多模态情感分析中的样本质量差异非常明显。高质量视觉样本能够提供可靠表情线索，而低质量视觉样本可能只包含遮挡、偏转或模糊的人脸；高质量音频能够体现语调变化，而低质量音频可能被噪声掩盖。若对二者施加相同蒸馏权重，模型可能在低质量样本上学习到不稳定约束。本文因此将蒸馏损失权重设计为样本级动态变量，使蒸馏强度与模态质量和训练阶段共同相关。

### 2.3 自适应损失权重

在多任务学习中，不同损失项的尺度、收敛速度和优化难度往往不同，如何平衡多个目标是长期问题。Uncertainty Weighting 通过任务不确定性学习损失权重，GradNorm 通过梯度范数调整不同任务的训练速度，Dynamic Weight Average 根据历史损失变化率动态分配权重。这些方法证明了固定权重并非最优，动态权重能够提升训练稳定性和任务平衡性。

本文与上述方法的共同点是都试图避免人工设定固定权重，但差异在于本文面向多模态弱模态优化场景，将权重分解为三个具有明确语义的因子。可学习基值刻画某个辅助目标对当前任务的整体重要性，训练进度系数控制辅助损失进入训练的时间节奏，样本质量分数决定每个样本是否适合承受更强的蒸馏或对比约束。这种分解使权重变化不仅可学习，而且可解释、可消融、可与课程学习自然结合。

### 2.4 提示学习与动态提示

提示学习最初在自然语言处理和视觉语言模型中用于缩小预训练任务与下游任务之间的差距。CoOp 等方法将文本提示从人工模板扩展为可学习向量，CoCoOp 进一步引入条件提示，使提示能够根据输入图像动态变化。MaPLe 等方法则探索多模态提示之间的耦合关系。这些研究表明，提示不仅可以作为任务描述，也可以作为调节模型关注模式的可学习上下文。

在多模态情感分析中，提示机制仍处于较早阶段。MFON 将 prompt 引入模态提示注意力，用于增强文本与弱模态交互，但该 prompt 是全局共享参数，对所有输入样本相同。本文借鉴条件提示思想，提出动态提示生成模块，使提示由当前样本的文本与弱模态特征共同决定。这样，提示不再只是任务级偏置，而成为样本级跨模态交互控制信号。

### 2.5 课程学习

课程学习主张按照从易到难的顺序训练模型，使模型先掌握简单样本中的稳定规律，再逐步处理复杂样本。经典课程学习通常依赖人工定义的难度指标，例如句子长度、词频、噪声水平或标签置信度。近年来，许多方法开始使用模型自身的预测置信度、损失值或特征一致性估计样本难度。

本文的课程采样策略基于样本质量而非单纯任务损失。对于多模态情感分析而言，样本难度不仅取决于标签本身，也取决于各模态是否可靠。因此，本文使用视觉和声学质量分数构造课程顺序，使模型在训练早期优先处理模态线索较清晰的样本。与传统课程学习不同，本文的质量分数同时服务于损失权重和数据采样，使训练目标和样本选择保持一致。

## 3. 方法

### 3.1 任务定义与整体框架

给定一个多模态样本 $x = \{x_t, x_v, x_a\}$，其中 $x_t$ 表示文本序列，$x_v$ 表示视觉序列，$x_a$ 表示声学序列，多模态情感分析的目标是预测情感标签或连续情感强度 $y$。模型首先分别提取文本、视觉和声学表示：

$$
T = E_t(x_t), \quad V = E_v(x_v), \quad A = E_a(x_a),
$$

其中 $T \in \mathbb{R}^{l_t \times d}$，$V \in \mathbb{R}^{l_v \times d}$，$A \in \mathbb{R}^{l_a \times d}$ 分别表示投影到统一维度后的三种模态特征。文本编码器通常采用 BERT，视觉和声学特征可由 FACET/OpenFace 与 COVAREP 等工具提取后通过 MLP 映射到统一空间。

DAMFON 在 MFON 的弱模态优化框架基础上引入三个动态机制。对于视觉和声学模态，模型先通过动态提示生成模块得到样本级提示 $P_v(x)$ 和 $P_a(x)$，再通过模态提示注意力获得优化后的弱模态表示 $V'$ 和 $A'$。随后，模型计算模态内知识蒸馏损失 $L_{kd}^{v}$、$L_{kd}^{a}$ 和模态间对比损失 $L_{cl}$。与 MFON 使用固定权重不同，DAMFON 根据训练阶段和样本质量动态生成 $\alpha_v(t,x)$、$\alpha_a(t,x)$ 和 $\beta(t,x)$，从而得到总损失：

$$
L = L_{task} + \alpha_v(t,x)L_{kd}^{v} + \alpha_a(t,x)L_{kd}^{a} + \beta(t,x)L_{cl}.
$$

其中 $L_{task}$ 为情感预测主损失，分类任务使用交叉熵，回归任务使用 MAE 或 MSE。课程采样策略则在数据加载阶段利用样本质量分数控制每个 epoch 进入训练的样本集合。

### 3.2 自适应损失权重

辅助损失的作用并非在整个训练过程中保持不变。训练早期，模型尚未学到稳定的跨模态表示，弱模态特征和注意力输出可能包含较多噪声，此时强行施加蒸馏和对比约束容易干扰主任务学习。训练中后期，随着表示逐渐稳定，辅助损失能够更有效地提升弱模态判别性。因此，本文将辅助损失权重设计为训练阶段和样本质量的函数。

以视觉蒸馏权重为例，DAMFON 将其分解为：

$$
\alpha_v(t,x) = \operatorname{softplus}(\alpha_v^{base}) \cdot s(t) \cdot q_v(x),
$$

其中 $\alpha_v^{base}$ 是可学习基值，表示视觉蒸馏在当前任务中的整体重要性；$s(t)$ 是训练进度系数，控制蒸馏约束随 epoch 逐渐增强；$q_v(x)$ 是视觉模态质量分数，表示当前样本是否适合接受更强蒸馏监督。声学蒸馏权重 $\alpha_a(t,x)$ 采用相同形式。对比学习权重则使用视觉和声学质量的平均值：

$$
\beta(t,x) = \operatorname{softplus}(\beta^{base}) \cdot s(t) \cdot \frac{q_v(x)+q_a(x)}{2}.
$$

训练进度系数默认采用线性预热：

$$
s(t)=\min\left(\frac{t}{T_{warmup}},1\right),
$$

其中 $T_{warmup}$ 为预热 epoch 数。该设计使辅助损失在训练初期缓慢进入优化过程，避免不稳定弱模态表示过早影响主任务梯度。

样本质量分数可以由多种方式估计。本文考虑三类质量函数。第一类是范数质量 $q_{norm}$，假设特征范数越大，表示中包含的信息量越丰富。第二类是置信度质量 $q_{conf}$，使用模态预测分支的最大 softmax 概率作为可靠性估计。第三类是对齐质量 $q_{align}$，计算当前弱模态表示与冻结单模态教师特征之间的余弦相似度。三者分别从特征强度、预测确定性和教师一致性角度刻画样本质量。实验中将比较不同质量函数的效果，并分析其在不同数据集上的适用性。

### 3.3 动态提示生成

MFON 中的模态提示注意力使用静态可学习提示向量 $P_v$ 和 $P_a$，这些提示在训练后对所有样本共享。静态提示可以学习任务级先验，但无法根据样本质量和语义内容进行调整。本文提出动态提示生成模块，使提示由输入样本条件化生成。

具体而言，首先对文本表示进行平均池化得到全局语义向量 $\bar{T}$，对视觉或声学序列进行池化得到 $\bar{V}$ 和 $\bar{A}$。视觉动态提示由一个轻量 MLP 生成：

$$
P_v(x)=\operatorname{reshape}(\operatorname{MLP}_v([\bar{T};\bar{V}]), m, d),
$$

声学动态提示为：

$$
P_a(x)=\operatorname{reshape}(\operatorname{MLP}_a([\bar{T};\bar{A}]), m, d),
$$

其中 $m$ 为提示长度，$d$ 为隐藏维度，$[\cdot;\cdot]$ 表示向量拼接。MLP 由两层线性层、GELU 激活和 LayerNorm 组成，参数量远小于主干编码器。

得到动态提示后，视觉模态优化表示计算为：

$$
V' = \operatorname{CrossAttn}(Q=T,K=V,V=V) + \operatorname{CrossAttn}(Q=T,K=P_v(x),V=P_v(x)).
$$

声学模态 $A'$ 以相同方式计算。动态提示的作用可以理解为对跨模态注意力的样本级调制：当视觉信息可靠时，提示可引导模型更充分地利用视觉细节；当视觉信号较弱时，提示可使模型更多依赖文本语义上下文，避免对噪声视觉特征过拟合。

DPG 与 ALW 之间具有天然协同关系。DPG 提升弱模态表示质量后，质量分数 $q_v(x)$ 或 $q_a(x)$ 可能随之上升，进而使 ALW 增强相应样本的辅助损失权重。反过来，ALW 对低质量样本降低损失权重，可以减少 DPG 在噪声样本上受到的错误约束。二者共同构成质量感知的特征优化过程。

### 3.4 课程采样策略

标准随机采样会在训练一开始就将所有样本混合输入模型，其中包含大量高噪声、低质量或跨模态冲突明显的样本。对于多模态模型而言，这种训练方式可能使模型在尚未建立稳定模态对齐能力时受到困难样本干扰。本文提出课程采样策略，按照样本质量从易到难组织训练。

在每个 epoch 结束后，模型为训练集样本计算综合质量分数：

$$
q(x)=\frac{q_v(x)+q_a(x)}{2}.
$$

下一轮训练开始前，根据当前课程进度 $c(e)$ 选择样本子集：

$$
c(e)=\min\left(\frac{e}{E_{cur}},1\right),
$$

其中 $E_{cur}$ 为课程长度。设 $Q_e$ 为当前 epoch 前所有训练样本的质量分数集合，课程采样选择质量位于前 $c(e)$ 比例的样本：

$$
\mathcal{D}_e = \{x_i \mid q(x_i) \ge \operatorname{Percentile}(Q_e, 1-c(e))\}.
$$

因此，课程早期仅选择质量较高、较容易学习的样本；随着 $e$ 增大，阈值逐渐降低，更多中等质量和低质量样本被纳入训练，最终使用全部训练集。被选中的样本在 epoch 内仍进行随机打乱，以避免固定顺序带来的偏置。

需要注意的是，本文中的“容易样本”并不等价于任务损失最低的样本，而是指模态质量较可靠的样本。这样定义更符合多模态情感分析的特点：模型应先从模态线索清晰的样本中学习跨模态关联，再逐步处理模态冲突、噪声或弱信号样本。CSS 与 ALW 的区别在于，ALW 在损失层面调节每个样本的辅助监督强度，而 CSS 在数据层面调节样本进入训练的节奏。二者从不同角度降低早期训练方差。

### 3.5 即插即用扩展

为验证 DAMFON 的通用性，本文将 ALW、DPG 和 CSS 设计为相对独立的组件。ALW 只依赖辅助损失、训练步数和样本质量分数，因此可以接入任何包含多目标损失的 MSA 模型。DPG 依赖跨模态交互层，若目标模型中已有注意力模块，可以直接将静态提示替换为动态提示；若目标模型采用 MLP 融合，也可以将动态提示转化为门控向量，用于调制弱模态特征。CSS 只修改数据加载策略，与主模型结构无关。

在 MFON 中，DAMFON 可以原生替换固定权重和静态 prompt。在 Self-MM 中，ALW 可用于调节不同模态自监督损失的权重，DPG 可接入跨模态融合层，CSS 可根据模态质量组织训练样本。在 CubeMLP 中，DPG 可被实现为动态门控模块，对 MLP 融合后的视觉和声学特征进行样本级调制。通过跨架构验证，本文希望说明所提出方法不是依赖 MFON 细节的局部技巧，而是一种更一般的质量感知多模态优化框架。

## 4. 理论分析

本文从梯度方差角度解释自适应权重为何能够提升训练稳定性。设主任务损失梯度为 $g_{task}=\nabla_\theta L_{task}$，蒸馏损失梯度为 $g_{kd}=\nabla_\theta L_{kd}$。在固定权重 $\alpha$ 下，总梯度为：

$$
g = g_{task} + \alpha g_{kd}.
$$

其方差可写为：

$$
\operatorname{Var}(g)=\operatorname{Var}(g_{task}) + \alpha^2\operatorname{Var}(g_{kd}) + 2\alpha\operatorname{Cov}(g_{task},g_{kd}).
$$

在训练早期，弱模态表示尚不稳定，$g_{kd}$ 往往具有较大方差。如果 $\alpha$ 固定且不够小，辅助损失会显著放大总梯度方差，使优化路径更加震荡。对于低质量样本，蒸馏目标本身也可能不可靠，此时较大的 $\alpha$ 会进一步放大噪声样本的影响。

在 DAMFON 中，蒸馏权重为 $\alpha(t,x)=\alpha^{base}s(t)q(x)$。当训练处于早期时，$s(t)$ 接近零，使辅助梯度贡献被整体缩小；当样本质量较低时，$q(x)$ 较小，使该样本的辅助梯度进一步衰减。此时总梯度变为：

$$
g = g_{task} + \alpha^{base}s(t)q(x)g_{kd}.
$$

对应的蒸馏梯度方差项为：

$$
(\alpha^{base})^2s(t)^2q(x)^2\operatorname{Var}(g_{kd}).
$$

因此，在 $s(t)<1$ 或 $q(x)<1$ 的情况下，辅助梯度方差被显式压缩。该机制可以被视为一种质量感知的方差控制策略：模型不会完全丢弃辅助目标，而是根据训练阶段和样本可靠性决定其介入强度。

该分析也解释了 ALW、DPG 和 CSS 的协同。DPG 通过生成样本级提示提升弱模态表示质量，间接提高高质量样本的 $q(x)$；ALW 根据 $q(x)$ 控制辅助损失强度；CSS 根据 $q(x)$ 控制样本进入训练的顺序。三者共同降低低质量样本在训练早期造成的梯度扰动，同时保留中后期利用困难样本提升泛化能力的机会。

## 5. 实验设计

### 5.1 数据集与评价指标

本文计划在五个公开数据集上进行实验，包括 MOSI、MOSEI、CH-SIMS、UR-FUNNY 和 MUStARD。MOSI 和 MOSEI 是英文多模态情感分析中的经典基准，包含文本、视觉和声学三种模态，可用于二分类、七分类和回归评估。CH-SIMS 是中文多模态情感分析数据集，适合验证方法在跨语言场景下的有效性。UR-FUNNY 和 MUStARD 分别面向幽默检测和讽刺检测，这类任务对语义、语调和表情之间的复杂关系更加敏感，因此能够检验模型在挑战性跨域任务上的鲁棒性。

评价指标方面，分类任务使用 Acc-2、Acc-7 和 F1；回归任务使用 MAE 和 Corr。对于所有实验，本文将报告五个随机种子的均值和标准差，以降低随机初始化与数据采样带来的偶然性。

### 5.2 对比方法

对比方法覆盖早期融合、Transformer 融合、自监督多任务、MLP 融合和弱模态优化等类别。早期融合方法包括 TFN、LMF 和 MFM；跨模态 Transformer 方法包括 MulT 等；自监督与多任务方法包括 Self-MM；MLP 系方法包括 CubeMLP；弱模态优化方法以 MFON 为主要直接对标对象。本文还将报告 DAMFON 在不同质量函数设置下的结果，包括 DAMFON-$q_{norm}$、DAMFON-$q_{conf}$、DAMFON-$q_{align}$ 以及融合质量函数版本。

### 5.3 实现细节

文本编码器采用 BERT-base-uncased，视觉和声学特征按照各数据集常用预处理方式提取，并通过线性投影映射到统一隐藏维度。优化器使用 AdamW，主干学习率和动态权重参数学习率分别设置。ALW 的预热长度 $T_{warmup}$、CSS 的课程长度 $E_{cur}$、提示长度 $m$ 和质量函数温度系数将在验证集上选择。为保证公平比较，DAMFON 与 MFON 使用相同的主干编码器、训练轮数和早停策略。

### 5.6 训练动态与可视化

为解释 DAMFON 的训练行为，本文将绘制三类动态曲线。第一类是 $\alpha_v(t)$、$\alpha_a(t)$ 和 $\beta(t)$ 随 epoch 的变化，用于观察自适应权重是否符合预期：训练早期较小，中后期逐渐稳定，并根据不同模态质量形成差异。第二类是质量分数 $q_v(x)$ 和 $q_a(x)$ 的分布变化，用于分析模型是否逐渐学习到更可靠的弱模态表示。第三类是梯度范数和训练损失曲线，用于比较固定权重与自适应权重在收敛稳定性上的差别。

此外，本文将使用 t-SNE 或 UMAP 可视化 MFON 与 DAMFON 的弱模态表示。如果 DAMFON 有效，视觉和声学特征应当在情感类别或情感强度维度上呈现更清晰的结构，且与文本特征的对齐程度更高。

噪声鲁棒性实验用于检验 DAMFON 是否能够处理模态质量下降。具体做法是在视觉或声学输入中注入不同强度的高斯噪声，比较 MFON 与 DAMFON 的性能变化。

### 5.8 计算开销

DAMFON 的额外开销主要来自动态提示生成 MLP 和质量分数计算。由于 DPG 模块规模较小，其新增参数量相对于 BERT 和主干融合网络可以忽略。ALW 只增加少量可学习标量，CSS 主要影响数据加载顺序，不增加推理成本。在推理阶段，如果仅保留动态提示模块，则额外计算为一次轻量 MLP 前向；ALW 和 CSS 不参与推理。因此，DAMFON 预计能够在较低计算成本下获得更稳定的性能提升。

## 6. 讨论

DAMFON 的核心思想是将“模态质量”显式引入多模态训练过程。现有多模态融合方法往往默认所有模态在所有样本上都同等可靠，但这一假设在真实数据中并不成立。视觉模态可能因遮挡、角度或光照失效，声学模态可能因环境噪声或说话人差异失效，文本模态也可能因讽刺、反语或上下文缺失而产生歧义。因此，模型不应只学习如何融合模态，还应学习何时相信某个模态、何时降低某个辅助目标的影响，以及何时将困难样本纳入训练。

ALW、DPG 和 CSS 分别对应这一思想的三个层面。ALW 解决“辅助监督施加多强”的问题，DPG 解决“跨模态交互如何适应当前样本”的问题，CSS 解决“样本以何种顺序进入训练”的问题。三者共享质量估计，使训练过程具有一致的质量感知逻辑。与单纯增加模型容量相比，这种设计更强调优化路径和训练稳定性，因此尤其适合视觉、声学等弱模态质量波动较大的场景。

本文也存在若干局限。首先，质量函数仍具有一定启发式色彩，虽然本文比较了范数、置信度和对齐度三类指标，但更系统的模态质量定义仍值得研究。其次，动态提示提高了样本适应能力，但提示向量本身的可解释性有限，需要结合注意力热图或反事实实验进一步分析。最后，本文主要验证多模态情感分析任务，所提出方法是否能够直接推广到 VQA、跨模态检索或多模态讽刺解释等任务，还需要后续实验支持。

## 7. 结论

本文提出 DAMFON，一种面向鲁棒多模态情感分析的动态自适应模态特征优化网络。针对现有弱模态优化方法中固定损失权重、静态提示和随机采样的局限，DAMFON 分别设计了自适应损失权重、动态提示生成和课程采样策略。自适应损失权重通过基值、训练进度和样本质量三因子分解动态调节辅助损失强度；动态提示生成根据输入样本生成实例级提示，使跨模态注意力具备样本感知能力；课程采样策略利用质量分数组织从易到难的训练过程，降低早期噪声样本对优化的干扰。

后续工作将完成五个数据集上的主实验、消融实验和鲁棒性分析，并将 DAMFON 模块迁移到 Self-MM 和 CubeMLP 中验证其通用性。若实验结果符合预期，DAMFON 将为多模态情感分析中的弱模态优化提供一种低开销、可解释且易迁移的训练框架。
