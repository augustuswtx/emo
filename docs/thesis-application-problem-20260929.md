# 大论文具体应用领域与问题定义

Date: 2026-09-29
Status: current recommended positioning

## 1. 具体应用领域

**在线视频观点与产品评测视频的多模态情感分析。**

这类视频由用户面对镜头表达对产品、事件或体验的观点，模型同时使用：

- 转写文本中的评价内容；
- 声音中的语调、强弱和节奏；
- 画面中的表情、动作和视觉上下文。

MOSI 和 MOSEI 本身来源于在线观点视频，因此可作为方法开发和标准基准；
产品/汽车评测视频可作为大论文的应用确认场景。

## 2. 要解决的具体问题

在线视频中，文本通常承载明确评价，而声音和画面存在四类问题：

1. 背景噪声、压缩、帧丢失、遮挡或时间错位造成输入退化；
2. 清晰的画面或声音也可能与当前情感判断无关；
3. 冻结单模态教师可能给出与主任务冲突的辅助目标；
4. 对所有样本固定施加蒸馏和对比监督可能造成负迁移。

大论文要回答：

> **在在线视频观点分析中，怎样区分“输入看起来可靠”和“该辅助更新真的有用”，
> 并在固定训练预算下选择视觉、音频辅助监督？**

这是可验证的算法问题，不依赖必须建设大型商业舆情平台。

## 3. 推荐题目

首选：

**面向在线视频观点情感分析的非文本模态可信辅助学习方法研究**

偏应用的备选：

**面向产品评测视频的可靠多模态情感分析方法研究**

首选题目与现有 MOSI/MOSEI/SIMS 数据和算法工作更一致；只有在取得
MuSe-CaR 或其他产品评测原始视频并完成应用实验后，才使用第二个题目。

## 4. 大小论文如何共同解决这个问题

| 研究层次 | 具体问题 | 对应用的作用 |
|---|---|---|
| 唯一 CCF-B 小论文 | 先测量声音/画面的输入可靠性，再判断某个辅助更新是否真正降低独立主任务损失 | 在固定预算下识别不可靠输入、选择有帮助的监督并拒绝有害更新 |
| 大论文综合 | 方法能否跨数据集、骨干和真实/受控退化保持有效 | 确定在何种视频、模态和退化条件下可以使用该方法 |

现有小论文草稿作为这篇 CCF-B 小论文的第一版基础，不再另算一篇论文。升级
后的同一篇论文保留输入可靠性、逐样本损失、固定预算和作用性对照，并加入
任务效用预测与选择性辅助学习；大论文再扩展其跨设置验证和应用边界。

## 5. 数据集与应用关系

| 数据集 | 与应用领域的关系 | 用途 |
|---|---|---|
| MOSEI | 大规模在线视频观点表达 | 主开发、完整消融、多种子 |
| MOSI | 在线意见视频 | 快速实验和英文复现 |
| CH-SIMS/SIMS | 中文视听情感表达，含独立单模态标签 | 中文迁移和模态价值分析 |
| CH-SIMS v2.0 | 更多非语言线索与原始片段 | 方法冻结后的独立确认和原始媒体退化 |
| MuSe-CaR | 真实汽车评测视频 | 可选应用扩展；任务标签不同，不替代核心主表 |

现有三个数据集不需要更换。大论文若声称“产品评测视频应用”，至少需要一项
MuSe-CaR 或合法获得的产品评测原始视频实验；否则题目保持“在线视频观点”。

## 6. 可交付的应用结果

最低可运行原型可以输入一段观点视频或已有特征，并输出：

1. 片段级与整体情感预测；
2. 视觉和音频输入可靠性；
3. 训练阶段辅助监督被启用或拒绝的统计；
4. 低可靠、模态冲突或低置信片段提示；
5. 可导出的结果报告。

原型用于展示算法如何帮助视频观点分析，不需要接入爬虫、自动处罚、用户画像
或心理状态判断。

## 7. 论文贡献口径

如果实验成功，大论文可以形成三项相互衔接的贡献：

1. 面向在线视频观点分析的非文本模态可靠性与作用性审计协议；
2. 固定预算的逐样本辅助学习及其有效边界；
3. 稀疏任务效用监督下的选择性辅助学习方法及跨设置验证。

第三项目前仍是待验证方法，不能在开题或摘要中写成已取得的正向结果。
