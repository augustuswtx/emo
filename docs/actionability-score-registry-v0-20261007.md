# MFON/MOSEI 分数审计注册表 v0

日期：2026-10-07。状态：**预实验定义**；在新的跨分数审计结果出现前记录方向、计算口径和允许的比较。完成无结果的技术 smoke test 后冻结为 v1；若公式、样本选择或超参数需要改变，另存版本并说明原因。已有 MOSEI test、C1/C2/C5、P6/P7 均已被查看，不能再称为盲测确认。

## 要回答的问题

对同一条训练样本、同一模态，一个高分是否意味着应给它更多辅助 KL/InfoNCE 权重？先评估分数的原始语义，再评估在**相同平均权重预算**下的训练行动效果。五类候选分数均在相同的样本、checkpoint 和划分上计算；单个分数的高低不能自行证明其训练价值。

| ID / 类别 | 主分数（高分方向） | 取得方式 | 预设解释与限制 |
|---|---|---|---|
| S1 学得的退化可靠性 | `q_m`，越高表示训练时定义的退化越轻 | 现有 `vision_reliability` / `audio_reliability` | 只声称检测受控退化；不预设目标 KL 或梯度效用更好 |
| S2 教师一致性 | `-KL(student_m, frozen_teacher_m)`，越高表示分歧越小 | 现有逐样本 `per_sample_kl`；辅报 `(1+cosine)/2` | KL 可跨 batch 比较；InfoNCE 不作全局分数 |
| S3 输入可用性 | 非零时间步比例，越高表示该模态可用的特征片段越多 | 以 `sum(abs(feature_t)) > 1e-8` 判有效，除以总时间步；辅报 RMS 能量 | 可用性不等于真实性或有用性；控制填充与能量混淆 |
| S4 预测不确定性 | `-Var(ŷ_m^{(1)}, …, ŷ_m^{(K)})`，越高表示重复预测越稳定 | 计划用固定 `K=8` 次 dropout 预测，只打开 dropout、其他模块保持 eval；样本/种子固定 | 这是模型预测方差，不保证已校准；先做纯技术 smoke test 确认实现可重复 |
| S5 反事实模态影响 | `abs(ŷ_clean - ŷ_without_m)`，越高表示输出更受该模态影响 | 用零化对应模态特征的额外前向计算 | 零向量可能不在自然数据分布；输出变化不等于模态有益或因果重要性 |

这里的 `m` 是视觉或音频，`ŷ` 是情感回归输出。S4 使用同一融合输出作为样本级信号，不能把它说成区分视觉与音频的可靠性；只有实现了模态专属预测方差后才可做模态级分配。S2 的余弦是同一类别的第二种预先指定口径，不能把它和 KL 当作独立方法家族数。S3 的时间步阈值沿用现有审计约定；MOSI/SIMS 若填充规则不同须重新核实。S5 以无标签预测位移取代现有 C5 的有标签错误差值，因此 C5 数值**不能**直接当作 S5 结果。

## 参考标签与训练行动

现有 `proj_v.weight` 的任务梯度与逐样本视觉 KL 梯度点积，以及已校验的中心差分，是**情境依赖的局部更新参考标签**，不算第六类可部署的样本内在分数。每条标签必须同时记录 meta batch ID、辅助样本 ID、checkpoint、参数块、步长和梯度范数。P7 表明在已测设置下不能丢掉 meta 情境，把它当作稳定的样本属性。音频参考标签的梯度尺度很小，尚未通过同等可靠的数值校验；当前不拿它判断音频候选分数优劣。

训练对照采用同一辅助损失、模型初始化、seed、优化器与日程。每个 batch 内先按原始分数从低到高做平均秩（并列用平均秩），再令 `r_i=(rank_i-0.5)/B`、`w_i=2·base_weight·r_i`。这样平均权重恒为 `base_weight`；Direct、Permuted、Inverse 使用同一组权重值，只改变它们分给哪些样本。`B=1` 或全并列时退化为 Constant。历史 P4 Learned 保留原实现，另列为既有方法；秩标准化的 S1 是新的同预算机制比较，不把两者混为一组。

S1–S5 的“高分优先”只是事先指定的方向假设。每一项都要报告 Direct、Constant、Permuted、Inverse；若某类高分实际上不利于任务，只能报告反向证据，不能看过测试结果后重新命名分数方向。Permuted 的置换规则和全部随机种子也应在训练前固定。

主比较维持现有 KL+InfoNCE 辅助目标。S2 的主分数直接由 KL 构成，因此若它进入完整训练矩阵，另做 KL-only 消融，区分“按较小 KL 排序”与 InfoNCE 负例集合带来的影响。

## 评估与数据使用

1. **退化敏感度：**同样本的 clean/受控退化配对；报告 AUROC 与排序方向。S4/S5 计算昂贵，报告额外前向与时间。
2. **目标保真度：**使用 `-KL` 及长度/能量控制；S2 对 `-KL` 的自相关是定义事实，不能当作独立验证或论文发现。InfoNCE 只在同 batch 的负例集合内比较。
3. **更新稳定性：**训练集的独立 meta 情境、早/中/末 checkpoint 与至少两个 seed；报告符号一致、实际小步响应及数值阈值。这里允许某个分数因定义不适用而标记 N/A，但必须说明。
4. **分配作用性：**在同均值预算和配对 seed 下比较 Direct/Constant/Permuted/Inverse；报告实际加权损失、梯度范数、MAE、Corr、分类指标及额外计算成本。只有这一层能支持“分数指导权重有益”的结论。

MOSEI 已检查的 valid/test 结果都作开发及探索性证据。新分数的归一化、阈值和模型选择不得借助 MOSEI test；最终确认应来自事先锁定的跨数据集与跨骨干设置，并公开失败的设置。若某个分数无法在第二骨干中以相同语义计算，标记不可比，而不是换成另一个量后合并结果。
