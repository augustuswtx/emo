# 2026-07-29 新颖性边界更新

## 本次精读问题

围绕当前方法的两个关键部件复核最接近工作：

1. 干净—退化配对排序是否已有直接先例；
2. 动态权重保持固定总量是否已有理论或实现先例。

来源限定为正式论文页面、官方论文PDF和可核验预印本页面。

## 关键发现

### SAM-LML（EMNLP 2025）

SAM-LML已经构造原始、加噪和纯噪特征，并使用排序约束要求原始交互的注意力高于加噪交互。论文还评估高斯噪声、Laplace噪声、随机擦除以及不同噪声比例。

因此，以下表述不能作为本文独立创新：

- 首次使用干净—加噪样本对；
- 首次用排序损失监督低质量模态；
- 首次要求噪声越强权重越低。

本文仍可能保留的区别是：SAM-LML直接监督注意力，本文先把可靠性分数作为独立对象进行粒度、单调性、混淆、作用性和非坍缩审计，再用通过审计的分数控制训练期辅助损失预算。该区别必须由跨代理审计和作用性实验支持，不能只靠文字定义。

### QMF（ICML 2023）

QMF从泛化理论出发，要求动态融合权重满足：

- 与对应单模态损失负相关；
- 动态权重的期望可与静态权重相同。

因此，“保持平均权重，公平比较动态和静态方法”不是完全空白。本文固定预算的可区分点应严格写成：

- QMF控制的是决策级模态融合权重的分布期望；
- 本文控制的是每个有限mini-batch内、逐样本KL与InfoNCE训练辅助监督的精确平均权重；
- 本文使用置换、反转、常数和Oracle分数，在相同批次预算下检验分配对应关系是否产生作用。

固定预算公式本身仍不足以构成主要创新，其价值取决于是否排除了“减少监督总量造成表面收益”这一混淆。

### 质量作用性诊断（2026预印本）

Moon等人的诊断固定模型和输入，在测试样本间置换可靠性分数，以检查决策是否真正依赖这些分数。本文不能把“置换分数检查作用”写成首次提出。

可扩展的部分是：

- 从推理期决策扩展到训练期辅助监督；
- 在置换时精确保持批次预算；
- 同时检查预测、梯度、鲁棒曲线与权重坍缩；
- 加入退化单调性和长度/能量混淆审计。

## 当前最稳妥的贡献结构

1. 五维质量信号审计协议及跨代理证据；
2. MFON原型中批次聚合、先聚合后加权、自由权重坍缩和范数反向响应的实现级诊断；
3. 训练期逐样本辅助损失的有限批次精确预算控制，作为公平作用性实验的机制修复；
4. 正常、常数、置换、反转和Oracle分数的正负对照证据。

干净—退化排序可靠性头是实现主方法所需部件，但不单独列为原创贡献。

## 投稿风险与停止条件

- 如果五维审计只在MFON和MOSI成立，论文应收窄为案例研究或硕士论文章节。
- 如果固定预算方法只提高clean指标而不提高退化鲁棒性，不能宣称可靠学习有效。
- 如果置换、反转和Oracle分数在相同预算下几乎不改变结果，说明可靠性仍未真正作用。
- 如果无法与QMF和SAM-LML在一致退化协议下比较，相关结论必须限制在MFON辅助优化路径。
