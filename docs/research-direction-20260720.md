# MFON/Q-DAMFON 研究重构决策（2026-07-20）

> **应用主线更新**：大论文场景确定为“面向在线短视频评论的可靠多模态情感分析”。小论文采用“质量代理审计 + 干预式可靠性学习 + 预算约束逐样本辅助优化”，大论文在此基础上扩展 MuSe-CaR/CH-SIMS v2.0、长视频时序聚合和应用原型。完整路线见 `thesis-integration-roadmap-20260720.md`。

## 一句话结论

暂停把 `ALW + DPG + CSS` 当成待扩展的完整新模型；保留旧结果作为失败原型，转向“**质量信号是否有效且真正可作用**”的诊断驱动研究。

## 1. 现有实现审计

### P0-1：所谓逐样本质量实际是批次标量

`MOSI/models/model.py` 的三种质量函数都在 batch 维度执行 `.mean()`：

- `norm`：每个样本范数之后再求 batch 均值；
- `conf`：所有样本预测置信度求均值；
- `align`：每个样本余弦相似度之后再求均值。

因此同一批次所有样本共享一个 `q_v/q_a`，论文草稿中的“逐样本动态权重”与代码不一致。MOSEI 和 SIMS 中存在同样实现。

### P0-2：辅助损失已经先聚合，无法逐样本加权

KL 使用 `batchmean`，InfoNCE 最后执行 `.mean()`。即使质量分数改成向量，也必须先把 KL 和 InfoNCE 改成逐样本损失，才能进行 `q_i L_i` 加权。

### P0-3：自由可学习的正损失权重会自然坍缩

当前目标包含：

$$
L = L_{task} + \alpha_v L_v + \alpha_a L_a + \beta L_{nce},
$$

且 $L_v,L_a,L_{nce}\ge 0$。如果 $\alpha_v,\alpha_a,\beta$ 可独立学习而没有归一化、预算约束或对数补偿，降低总损失的直接方式就是把权重压向 0。日志中约 0.5 的初值下降到约 0.28，与这一退化方向一致。

### P0-4：DPG 不是显式质量引导

DPG 接收文本和模态表示，但没有接收 `q_v/q_a`。它可以被称为样本相关提示门控，不能被称为“由同一质量信号统一控制的提示模块”。

### P0-5：CSS 分数主要是有效序列长度代理

当前 CSS 使用视觉和声学原始特征的 RMS 范数作为“质量”。对本地 MOSI 训练集 1,284 个样本的可重复审计得到：

| 检查项 | 结果 |
|---|---:|
| `corr(CSS, 平均有效时间步数)` | 0.8694 |
| `corr(CSS, |情感标签|)` | -0.0540 |
| `corr(CSS, 情感标签)` | -0.1549 |
| `corr(视觉范数, 声学范数)` | 0.6992 |

这说明 CSS 主要优先保留更长、非零时间步更多的样本，而不是已被证明“更可靠”的样本。它更准确的名字是长度/能量课程，而非质量课程。

进一步向有效视觉/声学时间步加入逐级增强的高斯噪声后，范数型 CSS 分数反而单调升高：

| Split | `corr(噪声强度, mean CSS)` | 高噪声分数高于 clean 的样本比例 |
|---|---:|---:|
| train | 0.9687 | 99.69% |
| valid | 0.9704 | 99.56% |
| test | 0.9691 | 99.85% |

因此该代理不仅受到长度混淆，在加性噪声下还会把“更差”判断为“更好”。这构成停止继续使用当前 CSS 的直接证据。

## 2. 旧实验如何处理

三种子结果是真实实验，不删除、不伪装，但改变用途：

| 方法 | Has0 Acc-2 | Acc-7 | MAE | Corr | 解释 |
|---|---:|---:|---:|---:|---|
| 修复 baseline | 0.8270±0.0009 | 0.4505±0.0125 | 0.7258±0.0028 | 0.7943±0.0015 | 当前可信对照 |
| Q-DAMFON-light | 0.8299±0.0059 | 0.4398±0.0044 | 0.7284±0.0038 | 0.7955±0.0040 | 无全面优势；机制实现与叙述不符 |
| Full Q-DAMFON | 0.8285±0.0094 | 0.4393±0.0155 | 0.7396±0.0232 | 0.7940±0.0070 | 种子敏感，回归指标更差 |

旧结果可以支持“朴素质量代理和无约束动态权重不可靠”这一诊断，不能支持“Q-DAMFON 稳定优于 MFON”。

## 3. 推荐的新研究问题

> 在多模态情感分析中，常用质量代理何时真正反映模态可靠性，并且如何保证该信号在模型优化和预测中产生可审计的作用？

这比“再融一个模块”更适合当前证据，也更贴近 2026 年可靠多模态学习的前沿问题。

## 4. 暂定贡献结构

### 贡献 A：质量信号四项审计协议

1. **粒度**：质量必须是逐样本或逐片段，不能被 batch 聚合。
2. **有效性**：退化强度增加时，可靠性应单调下降，并能区分 clean/corrupt。
3. **去混淆**：质量不应主要由序列长度、特征能量、标签强度或说话人身份解释。
4. **作用性**：置换、反转或移除质量信号时，模型决策或训练梯度应发生可预期变化。
5. **非坍缩**：动态权重不能通过趋近 0 来机械降低目标函数。

### 贡献 B：满足审计约束的轻量干预

方法尚不命名，也暂不宣称新颖。最低设计要求是：

- 使用可验证的退化监督或排序监督学习可靠性，禁止直接把模态范数当质量真值；
- 将“采集可靠性”和“情感任务效用”分开估计，避免把高质量但无关的信号当作重要模态；
- 保留逐样本 KL/对比损失，再进行有约束的权重分配；
- 采用固定预算或归一化权重，阻止辅助权重整体坍缩；
- 质量信号必须显式进入一个可审计路径，而不是只在日志中出现。

该设计要在精读 QA-MoE、EBMC、SAM-LML、CPSC、MRUF 后再冻结，避免与近期论文撞车。

> **实现状态（2026-07-20）**：逐样本 KL/InfoNCE、逐样本质量向量和固定 batch 预算已经作为 `--use-budgeted-aux` 修复基线接入 MOSI/MOSEI/SIMS，并通过 8 项 CPU 测试。当前仍使用 `align/norm/conf` 旧代理，只能验证预算机制，不能代表“干预式可靠性学习”已经完成。

### 贡献 C：跨数据集、跨骨干的鲁棒证据

- 数据集：MOSI、MOSEI、SIMS；
- 骨干：MFON + 至少两个公开且结构不同的强基线；
- 条件：clean、缺失、时间遮挡、高斯噪声、特征置换、未知组合退化；
- 统计：5 个固定种子，均值/样本标准差、配对检验和置信区间；
- 诊断：质量-退化 Spearman、错误检测 AUROC、分数置换、长度偏差、权重分布；
- 成本：参数量、训练时间、推理延迟和显存。
